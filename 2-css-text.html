CSS – texty, fonty a pozadie

CSS (Cascading Style Sheets, kaskádové štýly) určuje, ako stránka vyzerá: farby, písmo, veľkosti, medzery aj pozadie. HTML hovorí čo na stránke je, CSS ako to vyzerá.

1Tri spôsoby, ako pridať CSS

Atribút style priamo v značke. Platí len pre ten jeden prvok – pri väčšej stránke rýchlo neprehľadné.

<h1 style="color: white; text-align: center;">Môj článok</h1>

CSS v značke <style> v hlavičke. Platí len pre túto jednu stránku – web s mnohými stránkami by musel mať štýly v každej z nich znova.

<head>
  <style>
    h1 { color: white; text-align: center; }
  </style>
</head>

Štýly v samostatnom súbore css/style.css, ktorý pripojíme značkou <link> v hlavičke. Atribút rel="stylesheet" hovorí, v akom vzťahu je súbor k stránke (je to jej štýl), href kde ho nájde. Jeden súbor môže použiť každá stránka webu. Toto je spôsob, ktorý budeme používať.

index.html
<head>
  <meta charset="UTF-8">
  <title>Môj článok</title>
  <link rel="stylesheet" href="css/style.css">
</head>
css/style.css
h1 {
  color: white;
  text-align: center;
}

3Farby

Farbu textu nastaví vlastnosť color, farbu pozadia background-color. Hodnotu môžeš zapísať slovom (je ich vyše 140) alebo kódom – všetky zápisy vpravo znamenajú tú istú farbu.

Hex kód #rrggbb = červená, zelená, modrá v šestnástkovej sústave (00 – ff). rgb() to isté v desiatkovej (0 – 255), hsl() = odtieň (0 – 360°), sýtosť a svetlosť v percentách.

4Štýlovanie textu

Pohraj sa s posuvníkmi – CSS sa píše samo. font-family uvádza zoznam fontov: prehliadač použije prvý, ktorý v počítači nájde, a na konci je vždy všeobecná rodina (sans-serif, serif, monospace), ktorú nájde určite. Rodinu fontov je dobré nastaviť už pre body – zdedí ju celá stránka.

Nadpis článku

Toto je ukážkový odsek. CSS mení jeho písmo, veľkosť, hrúbku, medzery medzi písmenami aj riadkami. Zarovnanie do bloku (justify) uvidíš najlepšie pri dlhšom texte, ktorý má viac riadkov.

6Pozadie

      
Obrázok na pozadí zadávame cestou v url(). Pozor – cesta sa počíta od súboru CSS, nie od HTML. Zo súboru css/style.css preto musíme najprv vyjsť von z priečinka css pomocou ../ a až potom ísť do img: url("../img/hory.jpg").

      

        

        

          
Text na pozadí

          

        

      

      

        
background-size
cover – obrázok prekryje celý prvok (niečo sa môže orezať). contain – celý obrázok sa zmestí dnu (môže ostať voľné miesto, ktoré sa vyplní opakovaním).

        
background-repeat
predvolene sa obrázok opakuje; no-repeat opakovanie vypne, repeat-x / repeat-y len v jednom smere.

        
background-position
súradnice x y od ľavého horného rohu: slovom (right top), v percentách (10% 0%) alebo v px.

        
linear-gradient()
prechod farieb namiesto obrázka. Hotové gradienty nájdeš na uigradients.com.

      

      
background-attachment: scroll vs. fixed

      
Posuň text v oboch okienkach. Pri scroll (predvolené) sa pozadie posúva s obsahom, pri fixed stojí na mieste.

8Úlohy na hodinu

      
Pracuj s externým súborom css/style.css. Na kontrolu vlož do poľa pod zadaním HTML a CSS spolu – CSS daj do značky <style> (kontrola nevidí súbory na tvojom disku). Kontrola si stránku vykreslí a zmeria výsledné štýly.

      

        

          

            
Úloha 1 · Nadpisy a texty

            
    
              
  • Stránka s hlavným nadpisom (1×), podnadpismi (2×) a odsekmi (3×).
    • 
              
  • Celému body nastav rodinu fontov.

  • Nadpisy nech majú inú farbu ako text, sú hrubé, VEĽKÝMI písmenami (cez CSS!) a zarovnané na stred.

  • Hlavný nadpis 35 px, podnadpisy 25 px.
    • 
              
  • Texty 16 px s výškou riadka 1.5em.

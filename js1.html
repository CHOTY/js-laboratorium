1Čo je JavaScript?

Skriptovací jazyk, ktorý riadi správanie stránky – čo sa stane po kliknutí, kontrolu formulárov, vyskakovacie okná… Vie meniť HTML aj CSS. Pôvodne bežal len v prehliadači (frontend), dnes aj na serveri (backend). A pozor: JavaScript nie je Java – majú len podobné meno.

🧩

🌐

funguje vo všetkých moderných prehliadačoch

zložené zátvorky, bodkočiarky, if, for…
Vyskúšaj: case sensitive

console.log(meno);  // funguje
console.log(Meno);  // M ≠ m
Aj príkazy a objekty

Console.log("Toto nie");

6var, let, const – aký je rozdiel?

      
Všetky tri vytvoria premennú, ale správajú sa inak. Spusti príklady a porovnaj výsledky.

      

        

          

            
var nevidí blok { }


var x = 1;
if (x == 1) {
  var x = 2;
  console.log(x);
}
console.log(x);

            
            

            
Vnútorné var x prepísalo vonkajšie – obe sú tá istá premenná.

          

        

        

          

            
let platí len v bloku { }


let x = 1;
if (x == 1) {
  let x = 2;
  console.log(x);
}
console.log(x);

            
            

            
Vnútorné x existuje len medzi { } – vonkajšie zostalo 1. Tomu sa hovorí block scope.

          

        

        

          

            
let sa nedá vytvoriť dvakrát


let a = 10;
let a = 20;
console.log(a);

            
            

            
S var by to prešlo bez chyby – a preklep v mene by sa ľahko stratil.

          

        

        

          

            
const sa nedá zmeniť


const PI = 3.141592653589793;
PI = 3.14;
console.log(PI);

            
            

            
Hodnota const musí byť priradená hneď: const PI; je tiež chyba.

          

        

      

      

        Pravidlo pre dnešný JavaScript:
        
    
          
  • const – vždy, keď sa hodnota nebude meniť (to je väčšina premenných),
    • 
          
  • let – keď sa hodnota mení (počítadlo, súčet, i v cykle),
    • 
          
  • var – už nepoužívame. Uvidíš ho v starom kóde a na internete, preto ho treba poznať.

    15Cvičenie: registračný formulár
    
      
    Vytvor formulár (môžeš použiť Bootstrap) s poľami meno (text), vek (number), pohlavie (radio), e-mail, krajina (select), heslo, zopakované heslo, súhlas GDPR (checkbox) a tlačidlom na odoslanie. Po kliknutí na odoslanie skontroluj údaje v JavaScripte:
    
      
    
        
    
          
    PolePravidlo
    
          
            
    Menonesmie byť prázdne
    
            
    Vekaspoň 18
    
            
    E-mailnesmie byť prázdny a musí mať správny tvar
    
            
    Heslonesmie byť prázdne, aspoň 8 znakov, aspoň 1 malé písmeno, 1 veľké písmeno a 1 číslo
    
            
    Zopakované heslomusí sa zhodovať s heslom
    
            
    GDPRmusí byť zaškrtnutý
    
              
        
    
      
    
      
    O chybách informuj používateľa cez alert. Ak je všetko v poriadku, presmeruj ho na druhú stránku s poďakovaním a tlačidlom na návrat späť.
    

      
    
        
    
          
    Nápovedy
    
          
    
            1. Ako zachytiť odoslanie formulára

    const formular = document.getElementById("registracia");

formular.addEventListener("submit", function (event) {
  event.preventDefault(); // formulár sa neodošle, kým ho neskontrolujeme
  // ...kontroly...

            3. Ako skontrolovať heslo

    heslo.length >= 8      // dĺžka
/[a-z]/.test(heslo)     // obsahuje malé písmeno
/[A-Z]/.test(heslo)     // obsahuje veľké písmeno
/[0-9]/.test(heslo)     // obsahuje číslo
    
            
    /…/ je regulárny výraz – vzor, ktorý hľadáme v texte. [a-z] znamená „ktorékoľvek písmeno od a po z“. Metóda .test() vráti true, ak text vzor obsahuje.
    
          
    
          
    
            4. Ako skontrolovať e-mail

    const tvar = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
if (!tvar.test(email)) { ... }
    
            
    Čítaj: niečo bez medzier a @, potom @, potom niečo, bodka a niečo. ^ je začiatok a $ koniec textu.

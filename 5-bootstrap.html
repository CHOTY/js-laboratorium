Responzívne jednotky a Bootstrap

Najprv jednotky, s ktorými sa stránka prispôsobí obrazovke aj nastaveniu písma v prehliadači. Potom Bootstrap – hotové CSS a JavaScript, s ktorými postavíš responzívnu stránku za pár minút. Ukážeme si inštaláciu krok za krokom od úplného začiatku.

Zmeň šírku okna a porovnaj tri nadpisy – jeden v px, jeden vo vw a jeden s clamp():

Nadpis vo vw je na mobile drobný a na veľkom monitore obrovský. clamp() rastie s oknom, ale len v rozumných hraniciach. Inú možnosť – rôzne veľkosti pre rôzne zariadenia – poznáš z lekcie 4: media queries.

2Čo je Bootstrap

Bootstrap je najznámejší CSS framework – balík pripraveného CSS a JavaScriptu na stavbu responzívnych stránok. Vznikol v roku 2011 vo firme Twitter. Namiesto písania vlastného CSS pridávaš prvkom hotové triedy: class="btn btn-primary" spraví pekné modré tlačidlo, class="row" a class="col" rozložia stránku do stĺpcov. Základom je mriežka s 12 stĺpcami.

Výhody
  • zrýchli vývoj – mriežka, tlačidlá, formuláre, menu sú hotové
  • funguje rovnako vo všetkých prehliadačoch
  • čisté, súmerné rozloženie a dobré návyky (mobile-first)
  • obrovská dokumentácia a príklady
Nevýhody
  • stránky vyzerajú podobne („bootstrapovo“)
  • pridá veľa kódu, ktorý nepoužiješ
  • musíš sa naučiť jeho triedy a pravidlá
  • keď chceš niečo úplne iné, prepisovanie štýlov zaberie čas

Používame verziu 5.3. Dokumentácia: getbootstrap.com/docs/5.3.

3Inštalácia krok za krokom

Bootstrap sú v podstate dva súbory: bootstrap.min.css (štýly, patrí do hlavičky) a bootstrap.bundle.min.js (interaktívne časti ako rozbaľovacie menu či modálne okno, patrí na koniec <body>). Môžeš ich načítať z internetu (CDN) alebo stiahnuť do projektu. Prípona .min znamená minifikovaný súbor – bez medzier a komentárov, menší a rýchlejší; vhodný na zverejnený web.

  1. Priprav projekt

    Nový priečinok, v ňom index.html a css/style.css, otvorený v editore so spusteným Live Serverom – presne ako v lekcii 0.

  2. Nájdi odkazy na CDN

    CDN (Content Delivery Network) je server, z ktorého si prehliadač súbory stiahne. Na getbootstrap.com klikni na Docs → Get started → časť Quick start / Include via CDN. Sú tam dva riadky – <link> a <script>.

  3. CSS do hlavičky

    Riadok s <link … bootstrap.min.css> vlož do <head> za meta viewport. Tvoj style.css pripoj až za Bootstrap – tak môžeš jeho štýly prepísať.

  4. JavaScript na koniec body

    Riadok s <script … bootstrap.bundle.min.js> vlož tesne pred </body>. Bez neho sa stránka zobrazí, ale nebude fungovať rozbaľovanie menu, modálne okná ani zatváranie upozornení.

  5. Over, že to funguje

    Ulož a pozri do prehliadača: tlačidlo je fialovomodré a zaoblené (CSS funguje) a po kliknutí na „Vyskúšaj JavaScript“ sa rozbalí text (JS funguje). Ak nie, otvor F12 → Console a pozri chyby.

Celá kostra – skopíruj do index.html:

<!DOCTYPE html>
<html lang="sk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Moja stránka s Bootstrapom</title>
  <!-- 1. Bootstrap CSS -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <!-- 2. môj CSS až za ním -->
  <link href="css/style.css" rel="stylesheet">
</head>
<body>
  <div class="container py-5">
    <h1>Ahoj, Bootstrap!</h1>
    <button class="btn btn-primary" data-bs-toggle="collapse" data-bs-target="#test">
      Vyskúšaj JavaScript
    </button>
    <div class="collapse mt-3" id="test">
      <div class="alert alert-success">Funguje CSS aj JavaScript.</div>
    </div>
  </div>

  <!-- 3. Bootstrap JS na koniec body -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>

CDN potrebuje internet. Na stránke getbootstrap.com sú odkazy ešte doplnené atribútmi integrity a crossorigin – kontrolujú, že súbor nikto nepodvrhol; môžeš ich tam nechať.

  1. Stiahni skompilované súbory

    Na getbootstrap.com → Download klikni v časti Compiled CSS and JS na Download. Stiahne sa archív bootstrap-5.3.x-dist.zip.

  2. Rozbaľ a vyber, čo treba

    V archíve sú priečinky css a js s množstvom súborov. Stačia dva: css/bootstrap.min.css a js/bootstrap.bundle.min.js. (bundle = vrátane knižnice Popper pre rozbaľovacie menu a tooltipy; súbory .map nepotrebuješ.)

  3. Skopíruj ich do projektu

    my-website/ ├── index.html ├── css/ │ ├── bootstrap.min.css ← zo stiahnutého archívu │ └── style.css ← tvoje štýly └── js/ └── bootstrap.bundle.min.js

  4. Pripoj ich relatívnou cestou

    <head>
  …
  <link href="css/bootstrap.min.css" rel="stylesheet">
  <link href="css/style.css" rel="stylesheet">
</head>
<body>
  …
  <script src="js/bootstrap.bundle.min.js"></script>
</body>

  5. Over, že to funguje

    Rovnako ako pri CDN – vlož do body tlačidlo a rozbaľovací text z kostry vedľa. Výhoda: stránka funguje aj bez internetu. Ak sa štýly nenačítali, skontroluj cestu (F12 → Network – chyba 404 znamená zlú cestu).

Profesionálne projekty spravujú knižnice cez npm (správca balíkov pre Node.js). Na hodine to nepotrebuješ, ale je dobré vedieť, že existuje:

  1. Nainštaluj Node.js

    Z nodejs.org verziu LTS. Overíš v termináli príkazom node -v.

  2. Nainštaluj Bootstrap do projektu

    npm init -y
npm install bootstrap@5.3.3

  3. Pripoj súbory z node_modules

    <link href="node_modules/bootstrap/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="node_modules/bootstrap/dist/js/bootstrap.bundle.min.js"></script>

    V praxi sa súbory ďalej spracúvajú nástrojom (napr. Vite), ktorý ich zbalí s tvojím kódom.

Časté chyby

  • Chýba meta viewport – na mobile sa mriežka nezalomí a stránka je maličká.
  • Vlastný CSS je pred Bootstrapom – Bootstrap tvoje štýly prepíše. Tvoj <link> daj až za neho.
  • Návod pre starú verziu – v Bootstrape 3 a 4 (aj v starších materiáloch) sa písalo data-toggle, col-xs-6, glyphicon a potreboval jQuery. V Bootstrape 5 je to data-bs-toggle, col-6, ikony sú samostatná knižnica Bootstrap Icons a jQuery netreba.
  • Interaktívne časti nereagujú – chýba bootstrap.bundle.min.js, alebo si pripojil bootstrap.min.js bez Poppera.

4Breakpointy a kontajnery

Breakpoint je šírka obrazovky, pri ktorej sa rozloženie môže zmeniť. Bootstrap ich má šesť a ich skratky uvidíš v názvoch tried (col-md-6, d-lg-none…). Platí mobile-first: trieda so skratkou platí od danej šírky vyššie.

BreakpointSkratkaŠírka okna.container
Extra smallbez skratky< 576 px100 %
Smallsm≥ 576 px540 px
Mediummd≥ 768 px720 px
Largelg≥ 992 px960 px
Extra largexl≥ 1200 px1140 px
Extra extra largexxl≥ 1400 px1320 px
  • .container obalí obsah, vycentruje ho a na každom breakpointe mu dá maximálnu šírku.
  • .container-fluid má vždy 100 % šírky.
  • .container-md má 100 % až do md, potom sa správa ako .container.
  • Kontajnery sa dajú vnárať, ale väčšinou to netreba – jeden okolo obsahu stačí.

5Mriežka: row a col

Stĺpce sú vždy vnútri riadku .row a riadok vnútri kontajnera. Riadok má 12 dielikov: col-6 zaberie polovicu, col-4 tretinu. Samotné col si miesto rozdelí rovnakým dielom. Triedy s breakpointom sa dajú kombinovať: col-12 col-md-6 col-lg-3 = na mobile celá šírka, od tabletu polovica, od počítača štvrtina. Vyber rozloženie a meň šírku okna:

6Zarovnanie a medzery

      
Riadok .row je vo vnútri flexbox (lekcia 4), takže triedy pre zarovnanie fungujú rovnako: na riadok dávame justify-content-* (vodorovne) a align-items-* (zvislo), na jeden stĺpec align-self-*. Medzery medzi stĺpcami (gutters) nastaví g-*, len vodorovné gx-*, len zvislé gy-*.

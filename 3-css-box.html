1id a class – aký je medzi nimi rozdiel?

id – jedinečné meno

Na stránke smie byť len jeden prvok s daným id. V CSS ho vyberieš mriežkou #. Na štýlovanie sa používa menej – skôr na odkazy v rámci stránky (<a href="#kontakt">) a v JavaScripte.

#green {
  color: green;
}

class – skupina prvkov

Rovnakú triedu môže mať ľubovoľne veľa prvkov a jeden prvok môže mať viac tried naraz (class="card green"). V CSS ju vyberieš bodkou . – toto budeš používať najčastejšie.

.green {
  color: green;
}

2Box model – z čoho sa skladá každý prvok

Okolo každého HTML prvku je „krabica“ zložená zo štyroch vrstiev: obsah (content), vnútorný okraj padding, rámik border a vonkajší okraj margin. Rovnaký obrázok uvidíš v DevTools (F12 → Elements → Computed).

margin – priestor zvonkaborder – rámikpadding – priestor vnútricontent – obsah

        

      

      
box-sizing: predvolene (content-box) sa width týka len obsahu – padding a border sa pripočítajú navrch a prvok je väčší, ako si napísal. S border-box je width celková šírka vrátane paddingu a rámika. Preto mnohé stránky začínajú pravidlom * { box-sizing: border-box; }.

4Šírka a výška: width, height

      
Šírku zadávame v px (pevná) alebo v % – percentá sa počítajú zo šírky rodiča. Výšku nastaví rovnako height (pri percentách musí mať výšku nastavenú aj rodič). Zmeň šírku rodiča:

      
      
      

        
width: 250px

        
width: 50%

        
width: 20%

        
width: 100%

      

      
Prvok so šírkou v px môže byť širší ako rodič a „vytečie“ von. Percentá sa prispôsobia – to využijeme pri responzívnom dizajne.

    

  


  
  

    

      
5Block, inline a inline-block

      

        
block (div, p, h1–h6, section, ul…)
  • začína na novom riadku
  • zaberie celú šírku
  • funguje width, height a všetky marginy

        
inline (a, span, strong, em, b…)
  • pláva v texte vedľa ostatných
  • je široký len toľko, koľko obsah
  • ignoruje width a height, margin funguje len vľavo a vpravo
  • padding hore a dole prekrýva susedné riadky

        
inline-block – kompromis
  • ukladá sa vedľa seba ako inline
  • ale prijme width, height, margin aj padding zo všetkých strán
  • medzi prvkami ostane malá medzera (z medzery v HTML)

      

      
Typ zobrazenia zmeníš vlastnosťou display. Vyskúšaj, ako sa správajú tri <span> prvky s rovnakou šírkou, výškou a okrajmi:

Úloha 2 · Dobrodružstvo

            
Vytvor stránku na tému DOBRODRUŽSTVO. Všetky podmienky splnenia zadania nájdeš v kurze na edu.ukf.sk – téma 3, zadanie 3. Na štart môžeš použiť túto kostru:


<header id="top">
  <h1>Dobrodružstvo</h1>
  <nav>
    <a href="#hory">Hory</a>
    <a href="#more">More</a>
  </nav>
</header>
<main>
  <section id="hory" class="trip">
    <h2>Výstup na vrchol</h2>
    <img src="img/hory.jpg" alt="zasnežený vrchol hory">
    <p>…</p>
  </section>
  <section id="more" class="trip">
    <h2>Plavba po mori</h2>
    <p>…</p>
  </section>
</main>
<footer><a href="#top">Späť hore</a></footer>

CSS – text, fonts and backgrounds

CSS (Cascading Style Sheets) decides how a page looks: colours, fonts, sizes, spacing and backgrounds. HTML says what is on the page, CSS how it looks.

1 · Where to write CSS 2 · A CSS rule 3 · Colours 4 · Text and fonts 5 · px, em, rem 6 · Backgrounds 7 · Quiz 8 · Tasks

1Three ways to add CSS

The style attribute right in the tag. It applies only to that one element – on a bigger page it quickly gets messy.

<h1 style="color: white; text-align: center;">My article</h1>

CSS in a <style> tag in the head. It applies only to this one page – a site with many pages would need the styles in every one of them again.

<head>
  <style>
    h1 { color: white; text-align: center; }
  </style>
</head>

Styles in a separate file css/style.css, linked with a <link> tag in the head. The attribute rel="stylesheet" says how the file relates to the page (it is its stylesheet), href where to find it. Every page of the site can use the same file. This is the way we will use.

index.html
<head>
  <meta charset="UTF-8">
  <title>My article</title>
  <link rel="stylesheet" href="css/style.css">
</head>
css/style.css
h1 {
  color: white;
  text-align: center;
}

3Colours

The text colour is set by the color property, the background colour by background-color. You can write the value as a word (there are more than 140 of them) or as a code – all the notations on the right mean the same colour.

Hex code #rrggbb = red, green, blue in hexadecimal (00 – ff). rgb() is the same in decimal (0 – 255), hsl() = hue (0 – 360°), saturation and lightness in per cent.

4Styling text

Play with the sliders – the CSS writes itself. font-family gives a list of fonts: the browser uses the first one it finds on the computer, and at the end there is always a generic family (sans-serif, serif, monospace) that it will certainly find. It is a good idea to set the font family on body – the whole page inherits it.

6Backgrounds

      
A background image is given as a path in url(). Careful – the path is relative to the CSS file, not to the HTML. From css/style.css we first have to go out of the css folder with ../ and only then into img: url("../img/hory.jpg").

      

        

        

          
Text on the background

          

        

      

      

        
background-size
cover – the image covers the whole element (something may be cropped). contain – the whole image fits inside (there may be empty space, which is filled by repeating).

        
background-repeat
by default the image repeats; no-repeat turns repeating off, repeat-x / repeat-y only in one direction.

        
background-position
x y coordinates from the top left corner: in words (right top), in per cent (10% 0%) or in px.

        
linear-gradient()
a colour transition instead of an image. You will find ready-made gradients at uigradients.com.

      

      
background-attachment: scroll vs. fixed

      
Scroll the text in both boxes. With scroll (default) the background moves with the content, with fixed it stays in place.

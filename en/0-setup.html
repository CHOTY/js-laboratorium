Lesson 0

Editor and local server

Before we write our first line of HTML, we will set up the editor so that the page in the browser reloads by itself every time you save. Choose VS Code or Zed – both are free and run on Windows, macOS and Linux.

1Why isn’t double-clicking the file enough?

When you open an HTML file by double-clicking it, the browser loads it straight from the disk (the address starts with file://). That is fine for the first experiments, but you have to reload every change by hand and some things we will do later do not work this way at all. A local server is a small program that “serves” your folder to the browser like a real website – at the address http://127.0.0.1:… (127.0.0.1 or localhost = your own computer).

  • The page reloads by itself after you save the file
  • Loading another file with JavaScript (fetch()) – we will need it in the XML lesson
  • JavaScript modules (<script type="module">)
  • Paths from the site root, e.g. /img/logo.png
  • Ordinary HTML, CSS and images with a relative path (img/logo.png)

2One project = one folder

Both the editor and the server work with a whole folder, not with a single file. So create a folder on your disk (e.g. on the Desktop) with a file called index.html in it – the browser opens it as the home page. Other files go into subfolders.

my-website/ ├── index.html ← home page ├── css/ │ └── style.css ← lesson 2 ├── img/ │ └── logo.png └── js/ └── app.js ← JS 1

Put this skeleton into index.html (in VS Code the shortcut ! and Tab writes it for you):

<!DOCTYPE html>
<html lang="sk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My first page</title>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>If you see this at http://127.0.0.1, the server works.</p>
</body>
</html>

Tip: don’t use spaces or accented letters in file and folder names – my-page.html, not My page.html.

3Editor setup step by step

Choose one editor. In class we will show VS Code, but everything works the same way in Zed.

  1. Download and install VS Code

    Download it from code.visualstudio.com/Download for your system and install it. On Windows keep Add to PATH and Open with Code ticked – you can then open a folder with a right-click.

  2. Open the project folder

    Menu File → Open Folder… and choose the my-website folder (not a single file). If VS Code asks whether you trust the authors of the files, click Yes, I trust the authors.

  3. Install the extensions

    Click the Extensions icon on the left (four squares) or press Ctrl + Shift + X. Search for each of these and click Install:

    Live Server
    by Ritwick Dey
    local server with automatic reload
    Auto Close Tag
    by Jun Han
    writes the closing tag for you
    Prettier – Code formatter
    by Prettier
    fixes the indentation of your code

  4. Create index.html

    In the Explorer panel click the New File icon and type index.html. In the empty file type !, press Tab (Emmet inserts the page skeleton) and save with Ctrl + S.

  5. Start the server – Go Live

    Click Go Live in the blue status bar at the bottom right. Other options: right-click index.html → Open with Live Server, or Alt + L, then Alt + O. The browser opens at http://127.0.0.1:5500/index.html.

    index.html — my-website
    Ln 9, Col 5UTF-8HTML⦿ Go Live

  6. Edit, save, look

    Change the text in <h1> and save. The browser reloads by itself. So that you don’t have to keep saving, turn on File → Auto Save. Prettier tidies up messy code: right-click → Format Document (Shift + Alt + F).

  7. Stop the server

    Instead of Go Live the status bar now says Port : 5500 – click it to stop the server (or Alt + L, Alt + C).

  1. Download and install Zed

    Download it from zed.dev/download (macOS, Linux and Windows). On Linux you can also install it with the command curl -f https://zed.dev/install.sh | sh.

  2. Open the project folder

    Menu File → Open… (Ctrl + O) and choose the whole my-website folder. You will see the files on the left in the Project panel.

  3. Install the LiveServer extension

    Open the extensions page: Ctrl + Shift + X, or the command palette Ctrl + Shift + P → zed: extensions. Search for LiveServer (by frederik) and click Install. Zed installs HTML support by itself the first time you open an .html file. If you want the same shortcuts as in VS Code, add the Emmet extension too.

  4. Create index.html

    Right-click the folder in the Project panel → New File, type index.html and paste the page skeleton from part 2 (with the Emmet extension type ! and pick the suggestion from the menu). Save with Ctrl + S.

  5. Open the page in the browser – Code Action

    Right-click inside the text of index.html and choose Code Actions, or press Ctrl + . (full stop). Pick the LiveServer action from the menu – the page opens in the browser and Zed shows you which port the server runs on. The server keeps running while the project is open; you don’t have to start anything else.

    <h1>Hello, world!</h1>
    ⚡ LiveServer: open in browser
    …

    The exact name of the action may differ slightly depending on the extension version.

  6. Edit and watch the browser

    Changes show up immediately – depending on the settings while you type or after you save. When you change CSS only the styles are swapped; any other change reloads the page. Format your code via the command palette → editor: format.

4Fallback: a server from the terminal

If the extension can’t be installed (e.g. on a school computer), start a server from the terminal. In both editors the terminal opens with Ctrl + ` and is already in the project folder.

If you have Node.js – with automatic reload:

npx live-server

The first run downloads the package and opens the browser at http://127.0.0.1:8080.

If you have Python – without automatic reload:

python3 -m http.server 8000

On Windows py -m http.server 8000. Then open http://localhost:8000. Stop it with Ctrl + C.

5When it doesn’t work

Did you open the whole folder (Open Folder) and not just a file? Is the Live Server extension installed and enabled? Restarting VS Code also helps. You can start the server by right-clicking index.html → Open with Live Server as well.

Check that you saved the file – an unsaved file has a dot ● on its tab. Look at the address in the browser: if it starts with file://, the page is not running through the server. Are you editing a file from the same folder the server is serving?

The cursor has to be in an .html file that belongs to the opened folder. Check on the extensions page that LiveServer is installed and restart Zed. Until you sort it out, use a server from the terminal (part 4).

Another server is already running on the same port (e.g. from another editor window). Stop it, or let the server pick a different port – you will always see the number in the address.

The path is relative to the HTML file and upper/lower case matters: img/Logo.PNG is not the same as img/logo.png. On a web server (GitHub Pages too) such a mistake breaks the image even if it happens to work on Windows.

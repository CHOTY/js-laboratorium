2What responsive design is

      
Most people today come to the web on a phone. Responsive design means that the page adapts to the width of the screen by itself – nobody has to scroll sideways or zoom in with their fingers. When designing, we mainly deal with three things:

      

        
Font size
A 60 px heading looks fine on a computer but is far too big on a phone.

        
Spacing
On a big screen we want bigger margin and padding than on a small one.

        
Layout
4 columns side by side on a computer, the same columns stacked on a phone.

      

      
The basis is the <meta name="viewport" content="width=device-width, initial-scale=1.0"> tag in the head (lesson 1). Without it a phone would show a shrunk “desktop” version and the following tricks wouldn’t work.

    

  


  

    

      
3Flexbox – properties of the parent

      
Flexbox is a whole module for laying out elements. Some properties belong to the parent (flex container), others to the children (flex items). It all starts by giving the parent display: flex; – its children immediately line up side by side.

With flex-direction: column the axes swap – justify-content then aligns vertically and align-items horizontally. A detailed cheat sheet: CSS-Tricks – A Complete Guide to Flexbox.

    

  


  

    

      
4The children’s property: flex

      
The flex property says how many shares of the free space a child should take. If all of them have flex: 1, they split it equally; a child with flex: 2 gets twice as much as one with flex: 1. Click the numbers:

      

      

      

    

  


  

    

      
5Media queries – different CSS for different screens

      
The @media rule wraps a block of CSS that applies only when a condition is met – for example when the window is narrower than 600 px. The header below has the logo and the navigation side by side (flex, space-between). On a narrow screen it would break, so below 600 px we stack them with a 15 px gap. Change the width of the “window”:

      

        


header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

@media (max-width: 600px) {
  header {
    flex-direction: column;
    gap: 15px;
  }
}


          

          
max-width: 600px = “at most 600 px”, i.e. from 0 to 600 px. The opposite is min-width – “at least”. You can try the same in DevTools: F12 → the phone icon (Toggle device toolbar).

1Project requirements

Tick off what you have done. This browser remembers the list.

Meta tags for the head of every page

<meta name="description" content="A short description of the page">
<meta name="keywords" content="keywords, of, the, topic">
<meta name="author" content="First name Surname">
Not allowed: CMSs, site generators or any website-building platforms (e.g. WordPress, Wix). You write all the code yourself.

Pay attention to how the website looks: colours, fonts, spacing and images should work together.

2Folder structure

You hand in one .zip file. Inside it there is one folder with the same name, and the whole website is in that folder. Use lowercase letters without accents, e.g. novak_project.zip.

📚 surname_project.zip
 └ 📁 surname_project
     └ 📁 css
         └ 📄 style.css
     └ 📁 js
         └ 📄 app.js
     └ 📁 img
         └ 🖼️ imageXY.jpeg
     └ 📄 about.html
     └ 📄 blog.html
     └ 📄 contact.html
     └ 📄 gallery.html
     └ 📄 index.html
  • This is an example: name the subpages after your topic, but index.html is required.
  • The form also needs a thank-you page (e.g. thank-you.html) that it redirects to after sending.
  • If Bootstrap is downloaded into your project, its files also go into css/ and js/.
  • Name files in lowercase without spaces or accents. On a server Photo.JPG and photo.jpg are two different files.

Relative paths

page → pagehref="contact.html"
page → imagesrc="img/hills.jpg"
page → styleshref="css/style.css"
CSS → imageurl("../img/hills.jpg")

4Check your project before you submit

Choose your .zip. The check runs only in your browser and the file is not sent anywhere. It checks the name and folders, file paths, meta tags, separate CSS and JS, and tries to find the scored elements.

The check is a helper, not a grade. Check the look, the functionality and the validity (validator.w3.org) yourself; the teacher gives the points.

5Course assessment for Erasmus students

Conditions for passing

  • hand in the final project
  • pass the theory test from the lectures with at least 60 %

Erasmus students do not write the autotests, so they are not part of the grade.

At most 2 absences from the seminars are allowed, otherwise the student automatically gets FX. Arriving more than 5 minutes late counts as an absence.

1id and class – what is the difference?

id – a unique name

Only one element on a page may have a given id. In CSS you select it with a hash #. It is used less for styling – more for links within the page (<a href="#contact">) and in JavaScript.

#green {
  color: green;
}

class – a group of elements

Any number of elements can share the same class, and one element can have several classes at once (class="card green"). In CSS you select it with a dot . – this is what you will use most often.

.green {
  color: green;
}

2The box model – what every element is made of

Around every HTML element there is a “box” made of four layers: the content, the inner spacing padding, the border and the outer spacing margin. You will see the same picture in DevTools (F12 → Elements → Computed).

margin – space outsideborder – the framepadding – space insidecontent – the content

        

      

      
box-sizing: by default (content-box) width applies only to the content – padding and border are added on top and the element is bigger than what you wrote. With border-box, width is the total width including padding and border. That is why many sites start with the rule * { box-sizing: border-box; }.

4Width and height: width, height

      
Width is given in px (fixed) or in % – percentages are taken from the width of the parent. Height is set the same way with height (with percentages the parent must have a height too). Change the width of the parent:

      
      
      

        
width: 250px

        
width: 50%

        
width: 20%

        
width: 100%

      

      
An element with a width in px can be wider than its parent and “overflow” it. Percentages adapt – we will use that in responsive design.

    

  


  

    

      
5Block, inline and inline-block

      

        
block (div, p, h1–h6, section, ul…)
  • starts on a new line
  • takes the full width
  • width, height and all margins work

        
inline (a, span, strong, em, b…)
  • flows in the text next to others
  • is only as wide as its content
  • ignores width and height, margin works only left and right
  • top and bottom padding overlaps neighbouring lines

        
inline-block – a compromise
  • sits side by side like inline
  • but accepts width, height, margin and padding on all sides
  • a small gap remains between the elements (from the space in the HTML)

Lesson 1

HTML – the skeleton of every page

HTML is a markup language: it tells the browser what is on the page – a heading, a paragraph, an image, a link, a table, a form. How it looks is the job of CSS (lesson 2), and what happens after a click is the job of JavaScript.

1Tags, attributes and the document skeleton

A page is made of tags. Most of them come in pairs – an opening and a closing tag with the content in between: <p>…</p>. Void (unpaired) tags have no content: <br>, <img>, <input>, <meta>. Extra information goes into attributes in the opening tag: name="value".

The skeleton of every page

<!DOCTYPE html>
<html lang="sk">
  <head>
    <!-- information about the page – not visible -->
    <meta charset="UTF-8">
    <title>Title in the browser tab</title>
  </head>
  <body>
    <!-- everything that is visible on the page -->
    <h1>Hello, world!</h1>
  </body>
</html>

Project files

  • The home page is always called index.html – the browser opens it when the address doesn’t name a specific file.
  • Name other pages after their content (contact.html) – the file name also becomes part of the address.
  • Keep images in an img folder.
  • Tags nest inside each other like boxes: what opens last closes first – <p><strong>…</strong></p>.
  • The browser ignores indentation, but it helps you see the nesting.

4Links and images

      

        

          
Link <a>

          
    
            
  • href – where the link leads (required). A full address https://www.ukf.sk, another file of the project contact.html or a place on the page #form.
    • 
            
  • target="_blank" – opens the link in a new tab.
    • 
            
  • href="tel:+421900123456" – dials the number straight away on a phone.
    • 
            
  • href="mailto:info@firma.sk" – opens a new e-mail.
    • 
          

        

        

          
Image <img> (void tag)

          
    
            
  • src – path to the file including the extension (.jpg, .png, .gif, .svg). Required.
    • 
            
  • Relative path img/slnecnica.jpg – a file in your project. The recommended way.
    • 
            
  • External address https://…/obrazok.jpg – loads someone else’s server and the image can disappear at any time.
    • 
            
  • alt – a text description. Screen readers read it and it is shown when the image doesn’t load.
    • 
          

        

      

      

        

        

          
          

        

      

      


      

      
An external address always starts with the protocol: https://www.page.com/image.jpg (not http:www…). The alt attribute may contain accented letters too – thanks to <meta charset="UTF-8"> a screen reader reads them correctly.

7Forms

      
A form <form> collects data and, when submitted, sends it to the address in the action attribute. The method attribute sets how: GET adds the data to the address (e.g. a search), POST sends it hidden (registration, an order). target="_blank" would open the response in a new tab.

8Comments, developer tools and semantic tags

      

        

          
Comment

          
A note for the programmer – the browser doesn’t show it, not even inside <body>.


<!-- This is a comment. It starts with <!-- and ends with -->

          
It starts with two ordinary hyphens <!--, not a long dash.

        

        

          
Developer tools (DevTools)

          
On any page right-click → Inspect or press F12. In the Elements tab you see the HTML of the whole page, you can edit it temporarily, and below it you also see the CSS. With the three dots ⋮ you choose on which side of the window the panel appears. Try it on this page!

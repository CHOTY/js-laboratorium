Responsive units and Bootstrap

First the units that let a page adapt to the screen and to the font size set in the browser. Then Bootstrap – ready-made CSS and JavaScript with which you build a responsive page in a few minutes. We will go through the installation step by step from the very beginning.

1Responsive units

UnitRelative to whatWhen to use it
remthe font size of the root <html> (rem = root em, 16 px by default)fonts and spacing – when a visually impaired person enlarges the font in the browser, the page grows with it
emthe parent’s font size (body 5 px → paragraph 2em = 10 px)things that should grow with the text around them (button padding)
%the parent’s widthfluid columns – this is how the Bootstrap grid sets its widths too
vw / vh1 % of the width / height of the browser window (viewport)a section the full height of the screen (100vh), font size based on the window width
clamp(min, ideal, max)the ideal value, but never less than min and never more than maxresponsive font size without media queries: clamp(1.5rem, 5vw, 3rem)

Change the window width and compare three headings – one in px, one in vw and one with clamp():

The heading in vw is tiny on a phone and huge on a big monitor. clamp() grows with the window, but only within sensible limits. Another option – different sizes for different devices – you know from lesson 4: media queries.

2What Bootstrap is

Bootstrap is the best-known CSS framework – a package of ready-made CSS and JavaScript for building responsive pages. It was created at Twitter in 2011. Instead of writing your own CSS you add ready-made classes to elements: class="btn btn-primary" makes a nice blue button, class="row" and class="col" split the page into columns. At its core is a 12-column grid.

Advantages
  • speeds up development – the grid, buttons, forms and menus are ready
  • works the same in all browsers
  • clean, symmetrical layouts and good habits (mobile-first)
  • huge documentation and plenty of examples
Disadvantages
  • sites look alike (“bootstrappy”)
  • adds a lot of code you won’t use
  • you have to learn its classes and rules
  • if you want something completely different, overriding the styles takes time

We use version 5.3. Documentation: getbootstrap.com/docs/5.3.

3Installation step by step

Bootstrap is basically two files: bootstrap.min.css (the styles, goes into the head) and bootstrap.bundle.min.js (interactive parts such as dropdown menus or modal windows, goes at the end of <body>). You can load them from the internet (CDN) or download them into your project. The .min suffix means a minified file – without spaces and comments, smaller and faster; suitable for a published site.

  1. Prepare the project

    A new folder with index.html and css/style.css in it, open in your editor with Live Server running – exactly as in lesson 0.

  2. Find the CDN links

    A CDN (Content Delivery Network) is a server from which the browser downloads the files. On getbootstrap.com click Docs → Get started → the Quick start / Include via CDN part. There are two lines there – <link> and <script>.

  3. CSS into the head

    Put the line with <link … bootstrap.min.css> into <head> after the meta viewport. Link your style.css only after Bootstrap – that way you can override its styles.

  4. JavaScript at the end of body

    Put the line with <script … bootstrap.bundle.min.js> right before </body>. Without it the page still shows, but dropdown menus, modal windows and closing alerts won’t work.

  5. Check that it works

    Save and look at the browser: the button is purple-blue and rounded (CSS works) and after clicking “Try JavaScript” the text expands (JS works). If not, open F12 → Console and look at the errors.

The whole skeleton – copy it into index.html:

<!DOCTYPE html>
<html lang="sk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My page with Bootstrap</title>
  <!-- 1. Bootstrap CSS -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <!-- 2. my CSS only after it -->
  <link href="css/style.css" rel="stylesheet">
</head>
<body>
  <div class="container py-5">
    <h1>Hello, Bootstrap!</h1>
    <button class="btn btn-primary" data-bs-toggle="collapse" data-bs-target="#test">
      Try JavaScript
    </button>
    <div class="collapse mt-3" id="test">
      <div class="alert alert-success">Both CSS and JavaScript work.</div>
    </div>
  </div>

  <!-- 3. Bootstrap JS at the end of body -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>

A CDN needs the internet. On getbootstrap.com the links also have the attributes integrity and crossorigin – they check that nobody has tampered with the file; you can keep them.

  1. Download the compiled files

    On getbootstrap.com → Download click Download in the Compiled CSS and JS part. An archive bootstrap-5.3.x-dist.zip downloads.

  2. Unzip it and pick what you need

    The archive contains css and js folders with lots of files. Two are enough: css/bootstrap.min.css and js/bootstrap.bundle.min.js. (bundle = including the Popper library for dropdowns and tooltips; you don’t need the .map files.)

  3. Copy them into your project

    my-website/ ├── index.html ├── css/ │ ├── bootstrap.min.css ← from the downloaded archive │ └── style.css ← your styles └── js/ └── bootstrap.bundle.min.js

  4. Link them with a relative path

    <head>
  …
  <link href="css/bootstrap.min.css" rel="stylesheet">
  <link href="css/style.css" rel="stylesheet">
</head>
<body>
  …
  <script src="js/bootstrap.bundle.min.js"></script>
</body>

  5. Check that it works

    Same as with the CDN – put the button and the collapsible text from the skeleton next to this into body. The advantage: the page works even without the internet. If the styles didn’t load, check the path (F12 → Network – a 404 error means a wrong path).

Professional projects manage libraries with npm (the package manager for Node.js). You don’t need it in class, but it’s good to know it exists:

  1. Install Node.js

    The LTS version from nodejs.org. Check it in the terminal with the command node -v.

  2. Install Bootstrap into the project

    npm init -y
npm install bootstrap@5.3.3

  3. Link the files from node_modules

    <link href="node_modules/bootstrap/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="node_modules/bootstrap/dist/js/bootstrap.bundle.min.js"></script>

    In practice the files are processed further by a tool (e.g. Vite) that bundles them with your code.

Common mistakes

  • Missing meta viewport – on a phone the grid doesn’t wrap and the page is tiny.
  • Your own CSS comes before Bootstrap – Bootstrap overrides your styles. Put your <link> after it.
  • A tutorial for an old version – Bootstrap 3 and 4 (and older materials) used data-toggle, col-xs-6, glyphicon and needed jQuery. In Bootstrap 5 it is data-bs-toggle, col-6, icons are a separate library Bootstrap Icons and jQuery isn’t needed.
  • Interactive parts don’t respond – bootstrap.bundle.min.js is missing, or you linked bootstrap.min.js without Popper.

4Breakpoints and containers

A breakpoint is a screen width at which the layout can change. Bootstrap has six of them and you will see their abbreviations in class names (col-md-6, d-lg-none…). It is mobile-first: a class with an abbreviation applies from that width upwards.

BreakpointAbbreviationWindow width.container
Extra smallno abbreviation< 576 px100 %
Smallsm≥ 576 px540 px
Mediummd≥ 768 px720 px
Largelg≥ 992 px960 px
Extra largexl≥ 1200 px1140 px
Extra extra largexxl≥ 1400 px1320 px
  • .container wraps the content, centres it and gives it a maximum width at each breakpoint.
  • .container-fluid is always 100 % wide.
  • .container-md is 100 % up to md, then it behaves like .container.
  • Containers can be nested, but usually you don’t need to – one around the content is enough.

5The grid: row and col

Columns are always inside a .row and the row inside a container. A row has 12 shares: col-6 takes half, col-4 a third. A plain col shares the space equally. Classes with breakpoints can be combined: col-12 col-md-6 col-lg-3 = full width on a phone, half from a tablet up, a quarter from a computer up. 6Alignment and spacing

      
Inside, the .row is a flexbox (lesson 4), so the alignment classes work the same way: on the row we use justify-content-* (horizontally) and align-items-* (vertically), on a single column align-self-*. The spacing between columns (gutters) is set by g-*, horizontal only gx-*, vertical only gy-*.

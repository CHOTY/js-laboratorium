1Three types of functions

So far we have written functions in the form function nazovFunkcie() { … }. Depending on how many values a function gets, we distinguish three types:

without a parameter 
function ahoj() {
  return "Hello";
}
ahoj();  // "Hello"
with one parameter 
function pozdravMeno(meno) {
  return ahoj() + " " + meno;
}
pozdravMeno("Jožo");  // "Hello Jožo"
with several parameters 
function obsahStvorca(strana, jednotka) {
  return strana * strana + jednotka;
}
obsahStvorca(5, "cm");  // "25cm"

const bez_parametra = document.getElementById("bez_parametra");

2Anonymous functions

An anonymous function is a function without a name. It can have parameters like any other. Since we can’t call it by name, it is used in three ways:

1. Stored in a variable
const vynasob = function (x, y) {
  return x * y;
};

console.log(vynasob(2, 4));
The variable has the name, not the function.
2. Passed to another function
setTimeout(function () {
  console.log("1 second has passed");
}, 1000);

console.log("This is printed first");
setTimeout gets the function and runs it later. This is exactly how we will hand it to addEventListener in a moment.
3. Called immediately
// the function
(function () {
  console.log("This is an anonymous function");
})
// calling the function
();
The brackets around the function turn it into a value, () after them runs it straight away. This is called an IIFE.
You will most often see an anonymous function with events: tlacidlo.addEventListener("click", function () { … }); – the function has no name because we don’t call it anywhere else.

3Arrow functions

An arrow function isn’t a new type of function, just a shorter way of writing it. It doesn’t use the word function and assigns the function to a variable with an arrow =>. You will often see it in other programmers’ code. Choose a function and go through the conversion step by step.

5Three ways to react to a click

      
In the calculator we had onclick on every button and the HTML was messy. What if we had an accordion with 100 items? We can also set the reaction to a click directly in JavaScript, without touching the HTML.

      

        

          

            
a) the onclick attribute in HTML


<button id="myBtn" onclick="klik()">Click me</button>

function klik() {
  const btn = document.getElementById("myBtn");
  btn.innerHTML = "you clicked";
}

            
          

        

        

          

            
b) an event handler in JS


<button id="myBtn">Click me</button>

const btn = document.getElementById("myBtn");
function zmenText() {
  btn.innerHTML = "You clicked";
}
btn.onclick = zmenText;

            
          

        

        

          

            
c) addEventListener


<button id="myBtn">Click me</button>

const btn = document.getElementById("myBtn");
btn.addEventListener("click", () => {
  btn.innerHTML = "You clicked";
});

            
          

        

      

      

      
Careful: we pass the function without brackets

      

        

          

            
With brackets – wrong


function zmenText() {
  console.log("zmenText ran!");
}
const btn = document.createElement("button");
btn.onclick = zmenText();
console.log("btn.onclick is:", btn.onclick);

            
            

            
The function ran right when the page loaded and its result (nothing) was stored in onclick. Clicking then does nothing.

          

        

        

          

            
Without brackets – right


function zmenText() {
  console.log("zmenText ran!");
}
const btn = document.createElement("button");
btn.onclick = zmenText;
console.log("btn.onclick is:", btn.onclick);

            
            

            
We passed the function itself. The browser runs it only after the click.

An element can have only one handler of the same type – the second assignment overwrites the first. It can have as many listeners as it wants, and they run in the order in which we added them. That is why addEventListener is used in practice.


// the same with anonymous arrow functions
btn.addEventListener("click", () => { console.log(1); });
btn.addEventListener("click", () => { console.log(2); });

for (const a of accordion) {

An arrow function has no this of its own, so the accordion doesn’t work. If you want an arrow function, use the variable from the loop:


for (const a of accordion) {
  a.addEventListener("click", () => a.classList.toggle("active"));
}

        

      

      
Even better: put the listener on .question, not on the whole .accordion. Otherwise the accordion also closes when you click the answer (try it above). The solution: otazka.addEventListener("click", () => otazka.parentElement.classList.toggle("active"));

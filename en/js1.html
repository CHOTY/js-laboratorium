1What is JavaScript?

A scripting language that controls the behaviour of a page – what happens after a click, form validation, pop-up windows… It can change both HTML and CSS. Originally it ran only in the browser (frontend), today on servers too (backend). And careful: JavaScript is not Java – they only have similar names.

Why not to use document.write

      

        

          
The old way to “write something on the page” is document.write(). It only works while the page is loading. If you call it later (e.g. after a click), it wipes the whole page. Try it on the right.

          
The right way is to prepare an empty element in the HTML and put the text into it – we will learn that in detail in JS 2:


const meno = prompt("Enter your name", "");
document.getElementById("pozdrav").textContent = "Hello " + meno;

        

        

          

          
        

      

      
If no window opens after the click, the browser is blocking dialogs on this page (e.g. after you ticked “Don’t allow this page to ask again”). Reloading the page helps.

6var, let, const – what is the difference?

      
All three create a variable, but they behave differently. Run the examples and compare the results.

      

        

          

            
var doesn’t see the { } block


var x = 1;
if (x == 1) {
  var x = 2;
  console.log(x);
}
console.log(x);

            
            

            
The inner var x overwrote the outer one – both are the same variable.

          

        

        

          

            
let is valid only inside the { } block


let x = 1;
if (x == 1) {
  let x = 2;
  console.log(x);
}
console.log(x);

            
            

            
The inner x exists only between { } – the outer one stayed 1. This is called block scope.

          

        

        

          

            
let can’t be created twice


let a = 10;
let a = 20;
console.log(a);

            
            

            
With var this would pass without an error – and a typo in a name could easily get lost.

          

        

        

          

            
const can’t be changed


const PI = 3.141592653589793;
PI = 3.14;
console.log(PI);

            
            

            
A const must get its value straight away: const PI; is an error too.

          

        

      

      

        The rule for today’s JavaScript:
        
    
          
  • const – whenever the value won’t change (that is most variables),
    • 
          
  • let – when the value changes (a counter, a sum, i in a loop),
    • 
          
  • var – we don’t use it any more. You will see it in old code and on the internet, so you need to know it.

    Hints
    
          
    
            1. How to catch the form submission

    const formular = document.getElementById("registracia");

  // ...checks...

            2. How to read the values

    const meno = document.getElementById("meno").value;

            3. How to check the password

    heslo.length >= 8      // length
/[a-z]/.test(heslo)     // contains a lowercase letter
/[A-Z]/.test(heslo)     // contains an uppercase letter
/[0-9]/.test(heslo)     // contains a digit
    
            
    /…/ is a regular expression – a pattern we look for in text. [a-z] means “any letter from a to z”. The .test() method returns true if the text contains the pattern.
    
          
    
          
    
            4. How to check the e-mail

    const tvar = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
if (!tvar.test(email)) { ... }
    
            
    Read it as: something without spaces and @, then @, then something, a dot and something. ^ is the start and $ the end of the text.

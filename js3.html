1Tri typy funkcií

Doteraz sme písali funkcie v tvare function nazovFunkcie() { … }. Podľa toho, koľko hodnôt funkcia dostane, rozlišujeme tri typy:

bez parametra 
function ahoj() {
  return "Ahoj";
}
ahoj();  // "Ahoj"
s jedným parametrom 
function pozdravMeno(meno) {
  return ahoj() + " " + meno;
}
pozdravMeno("Jožo");  // "Ahoj Jožo"
s viacerými parametrami 
function obsahStvorca(strana, jednotka) {
  return strana * strana + jednotka;
}
obsahStvorca(5, "cm");  // "25cm"

2Anonymné funkcie

Anonymná funkcia je funkcia bez mena. Môže mať parametre ako každá iná. Keďže ju nemôžeme zavolať menom, používa sa tromi spôsobmi:

1. Uložená do premennej
const vynasob = function (x, y) {
  return x * y;
};

console.log(vynasob(2, 4));
Meno má premenná, nie funkcia.
2. Odovzdaná inej funkcii
setTimeout(function () {
  console.log("Prešla 1 sekunda");
}, 1000);

console.log("Toto sa vypíše skôr");
Funkciu dostane setTimeout a spustí ju neskôr. Presne takto ju o chvíľu odovzdáme addEventListener.
3. Zavolaná hneď
// funkcia
(function () {
  console.log("Toto je anonymná funkcia");
})
// zavolanie funkcie
();
Zátvorky okolo funkcie z nej spravia hodnotu, () za nimi ju hneď spustí. Hovorí sa tomu IIFE.
Najčastejšie uvidíš anonymnú funkciu pri udalostiach: tlacidlo.addEventListener("click", function () { … }); – funkcia nemá meno, lebo ju nikde inde nevoláme.

3Arrow funkcie

Arrow funkcia nie je nový typ funkcie, len kratší zápis. Nepoužíva slovo function a funkciu priradí do premennej pomocou šípky =>. Uvidíš ju často v kóde iných programátorov. Vyber si funkciu a prejdi prevod krok po kroku.


          

        

        

          
          
Konzola

          

            

              
Klasický zápisArrow zápis

              
                
function nahodneCislo() { return Math.random(); }const nahodneCislo = () => Math.random();

                
function umocni(x) { return x * x; }const umocni = (x) => x * x;

                
function vynasob(x, y) { return x * y; }const vynasob = (x, y) => x * y;

              
            

          

        

      

      

        

          

            
Pozor: so zloženými zátvorkami treba return


const zdvojnasob = (x) => { x * 2 };
const zdvojnasob2 = (x) => { return x * 2; };
const zdvojnasob3 = (x) => x * 2;

console.log(zdvojnasob(5), zdvojnasob2(5), zdvojnasob3(5));

            
            

          

        

        

          

            Kedy arrow funkciu nepoužiť: arrow funkcia nemá vlastné this. Ak v listeneri potrebuješ this (prvok, na ktorý sa kliklo), použi function () { … }. Uvidíme to na akordeóne v sekcii 7.
            

            V prezentácii sa používa var. Dnes píšeme const – funkciu v premennej už nemeníme.

  // každému pridáme listener

  });

Pokus: čo ak namiesto function napíšeme arrow funkciu?

      

        

          

            
Question 1

Question 2
Answer 2

          

          
Klikni na otázku vyššie

        

        


for (const a of accordion) {
  a.addEventListener("click", () => {
    this.classList.toggle("active");  // this tu NIE JE akordeón!
  });
}

          
Arrow funkcia nemá vlastné this, preto akordeón nefunguje. Ak chceš arrow funkciu, použi premennú z cyklu:


for (const a of accordion) {
  a.addEventListener("click", () => a.classList.toggle("active"));
}

        

      

      
Ešte lepšie: listener daj na .question, nie na celý .accordion. Inak sa akordeón zatvorí aj po kliknutí na odpoveď (vyskúšaj si to hore). Riešenie: otazka.addEventListener("click", () => otazka.parentElement.classList.toggle("active"));

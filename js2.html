1Čo je DOM?

DOM (Document Object Model) je strom objektov, ktorý si prehliadač vytvorí z HTML kódu. JavaScript nepracuje s textom HTML súboru, ale s týmto stromom – každá značka je objekt, ktorý vieme nájsť a zmeniť. Najvyššie je objekt document.

const pole = document.querySelector("#novaPolozka");
const zoznam = document.querySelector("#zoznam");

function pridajPolozku() {
  if (pole.value.trim() === "") {
    return; // prázdny text nepridáme
  }
  const li = document.createElement("li");
  li.textContent = pole.value;
  li.classList.add("list-group-item");
  zoznam.append(li);
  pole.value = ""; // vyčistíme input
}

11Úloha: kalkulačka

      
Takto má fungovať hotová kalkulačka. HTML a CSS máte pripravené v súbore kalkulacka.html, vašou úlohou je doprogramovať tri funkcie v js/kalkulacka.js.

      

        

          

            

              

                
                
              

              

              

              

              

            

          

        

        

          

            
              
display(x)pridá stlačený znak na koniec displeja

              
clearAll()vymaže displej

              
solve()vypočíta príklad na displeji a zobrazí výsledok

            
          

          

            Nápoveda 1 – kde je displej?
            
Displej je <input> s id="result". Nájdeš ho cez document.getElementById("result") a jeho obsah je vo vlastnosti .value – dá sa čítať aj prepisovať.

          

          

            Nápoveda 2 – funkcia display

function display(x) {
  const vysledok = document.getElementById("result");
  vysledok.value = vysledok.value + x;   // alebo skrátene +=
}

          

          

            Nápoveda 3 – ako vypočítať text „7*8+1“?
            
Najjednoduchšie je funkcia eval(text), ktorá text vyhodnotí ako JavaScript. Je však nebezpečná – vykoná akýkoľvek kód. Preto najprv skontroluj, že text obsahuje len čísla, bodku a znaky + - * /. Chyby (napr. „5++“) zachytíš cez try { … } catch { … }.

Unidades responsive y Bootstrap

Primero las unidades con las que la página se adapta a la pantalla y al tamaño de letra configurado en el navegador. Después Bootstrap: CSS y JavaScript ya hechos con los que montas una página responsive en pocos minutos. Veremos la instalación paso a paso desde el principio.

1Unidades responsive

UnidadRespecto a quéCuándo usarla
remel tamaño de letra de la raíz <html> (rem = root em, 16 px por defecto)letra y espacios: cuando una persona con baja visión agranda la letra en el navegador, la página crece con ella
emel tamaño de letra del padre (body 5 px → párrafo 2em = 10 px)cosas que deben crecer con el texto que las rodea (el padding de un botón)
%el ancho del padrecolumnas fluidas: así define sus anchos también la cuadrícula de Bootstrap
vw / vh1 % del ancho / alto de la ventana del navegador (viewport)una sección a toda la altura de la pantalla (100vh), letra según el ancho de la ventana
clamp(mín, ideal, máx)el valor ideal, pero nunca menos que el mínimo ni más que el máximoletra responsive sin media queries: clamp(1.5rem, 5vw, 3rem)

Cambia el ancho de la ventana y compara tres títulos: uno en px, uno en vw y uno con clamp():

El título en vw es diminuto en el móvil y enorme en un monitor grande. clamp() crece con la ventana, pero solo dentro de unos límites razonables. La otra opción, tamaños distintos para dispositivos distintos, ya la conoces de la lección 4: media queries.

2Qué es Bootstrap

Bootstrap es el framework CSS más conocido: un paquete de CSS y JavaScript ya preparados para crear páginas responsive. Nació en 2011 en la empresa Twitter. En lugar de escribir tu propio CSS, añades a los elementos clases ya hechas: class="btn btn-primary" crea un bonito botón azul, class="row" y class="col" dividen la página en columnas. Su base es una cuadrícula de 12 columnas.

Ventajas
  • acelera el desarrollo: la cuadrícula, los botones, los formularios y los menús ya están hechos
  • funciona igual en todos los navegadores
  • diseños limpios y simétricos y buenos hábitos (mobile-first)
  • una documentación enorme y muchos ejemplos
Inconvenientes
  • las páginas se parecen entre sí (“aspecto Bootstrap”)
  • añade mucho código que no usarás
  • tienes que aprender sus clases y reglas
  • si quieres algo totalmente distinto, sobrescribir los estilos lleva tiempo

Usamos la versión 5.3. Documentación: getbootstrap.com/docs/5.3.

3Instalación paso a paso

Bootstrap son básicamente dos archivos: bootstrap.min.css (los estilos, van en la cabecera) y bootstrap.bundle.min.js (las partes interactivas, como menús desplegables o ventanas modales, va al final de <body>). Puedes cargarlos desde internet (CDN) o descargarlos en tu proyecto. El sufijo .min significa archivo minificado: sin espacios ni comentarios, más pequeño y rápido; adecuado para una web publicada.

  1. Prepara el proyecto

    Una carpeta nueva con index.html y css/style.css, abierta en el editor con Live Server en marcha, exactamente como en la lección 0.

  2. Busca los enlaces del CDN

    Un CDN (Content Delivery Network) es un servidor del que el navegador descarga los archivos. En getbootstrap.com haz clic en Docs → Get started → la parte Quick start / Include via CDN. Ahí hay dos líneas: <link> y <script>.

  3. El CSS en la cabecera

    Pon la línea con <link … bootstrap.min.css> dentro de <head>, después del meta viewport. Enlaza tu style.css solo después de Bootstrap: así podrás sobrescribir sus estilos.

  4. El JavaScript al final de body

    Pon la línea con <script … bootstrap.bundle.min.js> justo antes de </body>. Sin ella la página se ve, pero no funcionarán los menús desplegables, las ventanas modales ni el cierre de los avisos.

  5. Comprueba que funciona

    Guarda y mira el navegador: el botón es azul violáceo y redondeado (el CSS funciona) y al hacer clic en “Prueba JavaScript” se despliega el texto (el JS funciona). Si no, abre F12 → Console y mira los errores.

El esqueleto completo: cópialo en index.html:

<!DOCTYPE html>
<html lang="sk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi página con Bootstrap</title>
  <!-- 1. Bootstrap CSS -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <!-- 2. mi CSS justo después -->
  <link href="css/style.css" rel="stylesheet">
</head>
<body>
  <div class="container py-5">
    <h1>¡Hola, Bootstrap!</h1>
    <button class="btn btn-primary" data-bs-toggle="collapse" data-bs-target="#test">
      Prueba JavaScript
    </button>
    <div class="collapse mt-3" id="test">
      <div class="alert alert-success">Funcionan el CSS y el JavaScript.</div>
    </div>
  </div>

  <!-- 3. Bootstrap JS al final de body -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>

Un CDN necesita internet. En getbootstrap.com los enlaces llevan además los atributos integrity y crossorigin: comprueban que nadie ha manipulado el archivo; puedes dejarlos.

  1. Descarga los archivos compilados

    En getbootstrap.com → Download haz clic en Download en la parte Compiled CSS and JS. Se descarga el archivo bootstrap-5.3.x-dist.zip.

  2. Descomprime y elige lo necesario

    El archivo contiene las carpetas css y js con muchos archivos. Bastan dos: css/bootstrap.min.css y js/bootstrap.bundle.min.js. (bundle = incluye la biblioteca Popper para desplegables y tooltips; los archivos .map no los necesitas.)

  3. Cópialos en tu proyecto

    my-website/ ├── index.html ├── css/ │ ├── bootstrap.min.css ← del archivo descargado │ └── style.css ← tus estilos └── js/ └── bootstrap.bundle.min.js

  4. Enlázalos con una ruta relativa

    <head>
  …
  <link href="css/bootstrap.min.css" rel="stylesheet">
  <link href="css/style.css" rel="stylesheet">
</head>
<body>
  …
  <script src="js/bootstrap.bundle.min.js"></script>
</body>

  5. Comprueba que funciona

    Igual que con el CDN: pon en body el botón y el texto desplegable del esqueleto de al lado. La ventaja: la página funciona también sin internet. Si los estilos no se cargaron, revisa la ruta (F12 → Network: un error 404 significa una ruta incorrecta).

Los proyectos profesionales gestionan las bibliotecas con npm (el gestor de paquetes de Node.js). En clase no lo necesitas, pero conviene saber que existe:

  1. Instala Node.js

    La versión LTS de nodejs.org. Compruébalo en la terminal con el comando node -v.

  2. Instala Bootstrap en el proyecto

    npm init -y
npm install bootstrap@5.3.3

  3. Enlaza los archivos de node_modules

    <link href="node_modules/bootstrap/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="node_modules/bootstrap/dist/js/bootstrap.bundle.min.js"></script>

    En la práctica los archivos los procesa después una herramienta (p. ej. Vite) que los empaqueta con tu código.

Errores frecuentes

  • Falta el meta viewport: en el móvil la cuadrícula no se reorganiza y la página se ve diminuta.
  • Tu CSS va antes de Bootstrap: Bootstrap sobrescribe tus estilos. Pon tu <link> después.
  • Un tutorial para una versión antigua: en Bootstrap 3 y 4 (y en materiales antiguos) se escribía data-toggle, col-xs-6, glyphicon y hacía falta jQuery. En Bootstrap 5 es data-bs-toggle, col-6, los iconos son una biblioteca aparte, Bootstrap Icons, y no hace falta jQuery.
  • Las partes interactivas no responden: falta bootstrap.bundle.min.js, o enlazaste bootstrap.min.js sin Popper.

4Breakpoints y contenedores

Un breakpoint es un ancho de pantalla a partir del cual la distribución puede cambiar. Bootstrap tiene seis y verás sus abreviaturas en los nombres de las clases (col-md-6, d-lg-none…). Es mobile-first: una clase con abreviatura se aplica desde ese ancho hacia arriba.

BreakpointAbreviaturaAncho de la ventana.container
Extra smallsin abreviatura< 576 px100 %
Smallsm≥ 576 px540 px
Mediummd≥ 768 px720 px
Largelg≥ 992 px960 px
Extra largexl≥ 1200 px1140 px
Extra extra largexxl≥ 1400 px1320 px
  • .container envuelve el contenido, lo centra y le da un ancho máximo en cada breakpoint.
  • .container-fluid mide siempre el 100 % del ancho.
  • .container-md mide el 100 % hasta md y después se comporta como .container.
  • Los contenedores se pueden anidar, pero normalmente no hace falta: con uno alrededor del contenido basta.

5La cuadrícula: row y col

Las columnas siempre van dentro de una fila .row y la fila dentro de un contenedor. Una fila tiene 12 partes: col-6 ocupa la mitad, col-4 un tercio. Un col sin número reparte el espacio a partes iguales. Las clases con breakpoint se pueden combinar: col-12 col-md-6 col-lg-3 = todo el ancho en el móvil, la mitad desde tableta, un cuarto desde ordenador. 6Alineación y espaciado

      
Por dentro, la fila .row es un flexbox (lección 4), así que las clases de alineación funcionan igual: en la fila ponemos justify-content-* (en horizontal) y align-items-* (en vertical), y en una sola columna align-self-*. El espacio entre columnas (gutters) lo define g-*, solo el horizontal gx-* y solo el vertical gy-*.

1¿Qué es JavaScript?

Un lenguaje de scripts que controla el comportamiento de la página: qué pasa al hacer clic, la validación de formularios, las ventanas emergentes… Puede cambiar el HTML y el CSS. Al principio solo funcionaba en el navegador (frontend); hoy también en el servidor (backend). Y ojo: JavaScript no es Java, solo se llaman parecido.

Por qué no usar document.write

      

        

          
La forma antigua de “escribir algo en la página” es document.write(). Solo funciona mientras la página se carga. Si lo llamas después (p. ej. tras un clic), borra toda la página. Pruébalo a la derecha.

          
Lo correcto es preparar un elemento vacío en el HTML y meter el texto en él; lo veremos en detalle en JS 2:


const meno = prompt("Escribe tu nombre", "");
document.getElementById("pozdrav").textContent = "Hola " + meno;

        

        

          

          
        

      

      
Si no se abre ninguna ventana al hacer clic, el navegador está bloqueando los diálogos de esta página (p. ej. después de marcar “No permitir que esta página vuelva a preguntar”). Ayuda recargar la página.

6var, let, const: ¿qué diferencia hay?

      
Las tres crean una variable, pero se comportan de forma distinta. Ejecuta los ejemplos y compara los resultados.

      

        

          

            
var no ve el bloque { }


var x = 1;
if (x == 1) {
  var x = 2;
  console.log(x);
}
console.log(x);

            
            

            
El var x interior sobrescribió al exterior: los dos son la misma variable.

          

        

        

          

            
let solo vale dentro del bloque { }


let x = 1;
if (x == 1) {
  let x = 2;
  console.log(x);
}
console.log(x);

            
            

            
La x interior solo existe entre { }; la exterior siguió valiendo 1. Esto se llama block scope.

          

        

        

          

            
let no se puede crear dos veces


let a = 10;
let a = 20;
console.log(a);

            
            

            
Con var pasaría sin error, y una errata en un nombre se perdería fácilmente.

          

        

        

          

            
const no se puede cambiar


const PI = 3.141592653589793;
PI = 3.14;
console.log(PI);

            
            

            
Una const debe recibir su valor de inmediato: const PI; también es un error.

          

        

      

      

        La regla para el JavaScript actual:
        
    
          
  • const – siempre que el valor no vaya a cambiar (la mayoría de las variables),
    • 
          
  • let – cuando el valor cambia (un contador, una suma, la i de un bucle),
    • 
          
  • var – ya no lo usamos. Lo verás en código antiguo y en internet, así que hay que conocerlo.

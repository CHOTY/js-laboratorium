1Requisitos del proyecto

Marca lo que ya tienes hecho. Este navegador recordará la lista.

Metaetiquetas para la cabecera de cada página

<meta name="description" content="Una breve descripción de la página">
<meta name="keywords" content="palabras, clave, del, tema">
<meta name="author" content="Nombre Apellido">
No se permite: usar un CMS, generadores ni plataformas para crear sitios web (p. ej. WordPress, Wix). Todo el código lo escribes tú.

Cuida también el aspecto del sitio: los colores, las fuentes, los espacios y las imágenes deben combinar bien.

2Estructura de carpetas

Entregas un solo archivo .zip. Dentro hay una carpeta con el mismo nombre y en ella está todo el sitio. Usa minúsculas sin tildes, p. ej. garcia_project.zip.

📚 apellido_project.zip
 └ 📁 apellido_project
     └ 📁 css
         └ 📄 style.css
     └ 📁 js
         └ 📄 app.js
     └ 📁 img
         └ 🖼️ imagenXY.jpeg
     └ 📄 blog.html
     └ 📄 contacto.html
     └ 📄 galeria.html
     └ 📄 index.html
     └ 📄 nosotros.html
  • Es un ejemplo: pon a las subpáginas nombres según tu tema, pero index.html es obligatorio.
  • El formulario necesita también una página de agradecimiento (p. ej. gracias.html) a la que redirige después de enviarlo.
  • Si tienes Bootstrap descargado en el proyecto, sus archivos también van en css/ y js/.
  • Nombra los archivos en minúsculas, sin espacios ni tildes. En un servidor Foto.JPG y foto.jpg son dos archivos distintos.

Rutas relativas

página → páginahref="contacto.html"
página → imagensrc="img/montes.jpg"
página → estiloshref="css/style.css"
CSS → imagenurl("../img/montes.jpg")

4Revisa tu proyecto antes de entregarlo

Elige tu .zip. La revisión se hace solo en tu navegador y el archivo no se envía a ningún sitio. Comprueba el nombre y las carpetas, las rutas, las metaetiquetas, que el CSS y el JS estén aparte, e intenta encontrar los elementos que puntúan.

La revisión es una ayuda, no una nota. El aspecto, el funcionamiento y la validez (validator.w3.org) los compruebas tú; los puntos los da el profesor.

5Evaluación para estudiantes Erasmus

Requisitos para aprobar

  • entregar el proyecto final
  • aprobar el examen teórico de las clases con al menos un 60 %

Los estudiantes Erasmus no hacen los autotests, así que no forman parte de la nota.

Se permiten como máximo 2 faltas a los seminarios; si no, el estudiante obtiene automáticamente FX. Llegar más de 5 minutos tarde cuenta como falta.
Proyecto final + Examen final2+Media de las tareas=Nota final

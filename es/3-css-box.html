1id y class: ¿qué diferencia hay?

id – un nombre único

En una página solo puede haber un elemento con un id concreto. En CSS lo seleccionas con almohadilla #. Se usa menos para dar estilo y más para enlaces dentro de la página (<a href="#contacto">) y en JavaScript.

#green {
  color: green;
}

class – un grupo de elementos

La misma clase la pueden tener todos los elementos que quieras, y un elemento puede tener varias clases a la vez (class="card green"). En CSS la seleccionas con un punto .: es lo que más usarás.

.green {
  color: green;
}

2El modelo de caja: de qué se compone cada elemento

Alrededor de cada elemento HTML hay una “caja” de cuatro capas: el contenido (content), el espacio interior padding, el borde border y el espacio exterior margin. Verás el mismo dibujo en DevTools (F12 → Elements → Computed).

margin – espacio exteriorborder – el bordepadding – espacio interiorcontent – el contenido

        

      

      
box-sizing: por defecto (content-box) width se refiere solo al contenido: el padding y el borde se suman encima y el elemento es más grande de lo que escribiste. Con border-box, width es el ancho total incluidos padding y borde. Por eso muchas páginas empiezan con la regla * { box-sizing: border-box; }.

margin y padding

Con cuatro valores vamos en el sentido de las agujas del reloj desde arriba: arriba, derecha, abajo, izquierda. 4Ancho y alto: width, height

      
El ancho se indica en px (fijo) o en %: los porcentajes se calculan sobre el ancho del padre. El alto se define igual con height (con porcentajes, el padre también debe tener un alto). Cambia el ancho del padre:

      
      
      

        
width: 250px

        
width: 50%

        
width: 20%

        
width: 100%

      

      
Un elemento con ancho en px puede ser más ancho que su padre y “salirse”. Los porcentajes se adaptan: lo aprovecharemos en el diseño responsive.

    

  


  

    

      
5Block, inline e inline-block

      

        
block (div, p, h1–h6, section, ul…)
  • empieza en una línea nueva
  • ocupa todo el ancho
  • funcionan width, height y todos los márgenes

        
inline (a, span, strong, em, b…)
  • fluye en el texto junto a los demás
  • solo es tan ancho como su contenido
  • ignora width y height; el margin solo funciona a izquierda y derecha
  • el padding de arriba y abajo se superpone a las líneas vecinas

        
inline-block – un término medio
  • se coloca uno al lado del otro como inline
  • pero acepta width, height, margin y padding por todos los lados
  • entre los elementos queda un pequeño hueco (del espacio en el HTML)

1Tres tipos de funciones

Hasta ahora hemos escrito funciones con la forma function nazovFunkcie() { … }. Según cuántos valores recibe una función, distinguimos tres tipos:

sin parámetro 
function ahoj() {
  return "Hola";
}
ahoj();  // "Hola"
con un parámetro 
function pozdravMeno(meno) {
  return ahoj() + " " + meno;
}
pozdravMeno("Jožo");  // "Hola Jožo"
con varios parámetros 
function obsahStvorca(strana, jednotka) {
  return strana * strana + jednotka;
}
obsahStvorca(5, "cm");  // "25cm"

2Funciones anónimas

Una función anónima es una función sin nombre. Puede tener parámetros como cualquier otra. Como no la podemos llamar por su nombre, se usa de tres maneras:

1. Guardada en una variable
const vynasob = function (x, y) {
  return x * y;
};

console.log(vynasob(2, 4));
El nombre lo tiene la variable, no la función.
2. Entregada a otra función
setTimeout(function () {
  console.log("Ha pasado 1 segundo");
}, 1000);

console.log("Esto se muestra antes");
setTimeout recibe la función y la ejecuta más tarde. Justo así se la entregaremos enseguida a addEventListener.
3. Llamada al instante
// la función
(function () {
  console.log("Esto es una función anónima");
})
// llamada a la función
();
Los paréntesis alrededor de la función la convierten en un valor y () detrás la ejecuta al momento. Se llama IIFE.
Donde más verás una función anónima es en los eventos: tlacidlo.addEventListener("click", function () { … });: la función no tiene nombre porque no la llamamos en ningún otro sitio.

3Funciones flecha

Una función flecha no es un tipo nuevo de función, solo una forma más corta de escribirla. No usa la palabra function y asigna la función a una variable con una flecha =>.

Lección 0

Editor y servidor local

Antes de escribir la primera línea de HTML, prepararemos el editor para que la página del navegador se recargue sola cada vez que guardes. Elige VS Code o Zed: los dos son gratuitos y funcionan en Windows, macOS y Linux.

1¿Por qué no basta con hacer doble clic en el archivo?

Cuando abres un archivo HTML con doble clic, el navegador lo carga directamente del disco (la dirección empieza por file://). Para los primeros intentos basta, pero tienes que recargar cada cambio a mano y algunas cosas que haremos más adelante no funcionan así en absoluto. Un servidor local es un pequeño programa que “sirve” tu carpeta al navegador como si fuera un sitio web real, en la dirección http://127.0.0.1:… (127.0.0.1 o localhost = tu propio ordenador).

  • La página se recarga sola al guardar el archivo
  • Cargar otro archivo con JavaScript (fetch()) – lo necesitaremos en la lección de XML
  • Módulos de JavaScript (<script type="module">)
  • Rutas desde la raíz del sitio, p. ej. /img/logo.png
  • HTML, CSS e imágenes normales con una ruta relativa (img/logo.png)

2Un proyecto = una carpeta

Tanto el editor como el servidor trabajan con una carpeta entera, no con un solo archivo. Por eso crea una carpeta en tu disco (p. ej. en el Escritorio) y dentro un archivo index.html: el navegador lo abre como página de inicio. Los demás archivos irán en subcarpetas.

my-website/ ├── index.html ← página de inicio ├── css/ │ └── style.css ← lección 2 ├── img/ │ └── logo.png └── js/ └── app.js ← JS 1

Pon este esqueleto en index.html (en VS Code lo escribe el atajo ! y Tab):

<!DOCTYPE html>
<html lang="sk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi primera página</title>
</head>
<body>
  <h1>¡Hola, mundo!</h1>
  <p>Si ves esto en la dirección http://127.0.0.1, el servidor funciona.</p>
</body>
</html>

Consejo: no uses espacios ni tildes en los nombres de archivos y carpetas: mi-pagina.html, no Mi página.html.

3Configurar el editor paso a paso

Elige un editor. En clase mostraremos VS Code, pero todo funciona igual en Zed.

  1. Descarga e instala VS Code

    Descárgalo de code.visualstudio.com/Download para tu sistema e instálalo. En Windows deja marcadas las opciones Add to PATH y Open with Code: así podrás abrir una carpeta con clic derecho.

  2. Abre la carpeta del proyecto

    Menú File → Open Folder… y elige la carpeta my-website (no un solo archivo). Si VS Code te pregunta si confías en los autores de los archivos, haz clic en Yes, I trust the authors.

  3. Instala las extensiones

    Haz clic en el icono Extensions de la izquierda (cuatro cuadrados) o pulsa Ctrl + Shift + X. Busca cada una y haz clic en Install:

    Live Server
    de Ritwick Dey
    servidor local con recarga automática
    Auto Close Tag
    de Jun Han
    escribe la etiqueta de cierre por ti
    Prettier – Code formatter
    de Prettier
    arregla la sangría del código

  4. Crea index.html

    En el panel Explorer haz clic en el icono New File y escribe index.html. En el archivo vacío escribe !, pulsa Tab (Emmet inserta el esqueleto de la página) y guarda con Ctrl + S.

  5. Inicia el servidor – Go Live

    Haz clic en Go Live en la barra de estado azul, abajo a la derecha. Otras opciones: clic derecho en index.html → Open with Live Server, o Alt + L y después Alt + O. El navegador se abre en la dirección http://127.0.0.1:5500/index.html.

    index.html — my-website
    Ln 9, Col 5UTF-8HTML⦿ Go Live

  6. Edita, guarda, mira

    Cambia el texto de <h1> y guarda. El navegador se recarga solo. Para no tener que guardar todo el rato, activa File → Auto Save. Prettier ordena el código desordenado: clic derecho → Format Document (Shift + Alt + F).

  7. Detén el servidor

    En lugar de Go Live la barra de estado muestra ahora Port : 5500: haz clic para detener el servidor (o Alt + L, Alt + C).

  1. Descarga e instala Zed

    Descárgalo de zed.dev/download (macOS, Linux y Windows). En Linux también puedes instalarlo con el comando curl -f https://zed.dev/install.sh | sh.

  2. Abre la carpeta del proyecto

    Menú File → Open… (Ctrl + O) y elige toda la carpeta my-website. Verás los archivos a la izquierda, en el panel Project.

  3. Instala la extensión LiveServer

    Abre la página de extensiones: Ctrl + Shift + X, o la paleta de comandos Ctrl + Shift + P → zed: extensions. Busca LiveServer (de frederik) y haz clic en Install. Zed instala solo el soporte de HTML la primera vez que abres un archivo .html. Si quieres los mismos atajos que en VS Code, añade también la extensión Emmet.

  4. Crea index.html

    Clic derecho en la carpeta del panel Project → New File, escribe index.html y pega el esqueleto de la página de la parte 2 (con la extensión Emmet escribe ! y elige la sugerencia del menú). Guarda con Ctrl + S.

  5. Abre la página en el navegador – Code Action

    Haz clic derecho dentro del texto de index.html y elige Code Actions, o pulsa Ctrl + . (punto). Elige en el menú la acción de LiveServer: la página se abre en el navegador y Zed te muestra en qué puerto funciona el servidor. El servidor sigue funcionando mientras el proyecto esté abierto; no tienes que iniciar nada más.

    <h1>¡Hola, mundo!</h1>
    ⚡ LiveServer: open in browser
    …

    El nombre exacto de la acción puede variar un poco según la versión de la extensión.

  6. Edita y mira el navegador

    Los cambios se ven al instante: según la configuración, mientras escribes o al guardar. Si cambias el CSS solo se reemplazan los estilos; cualquier otro cambio recarga la página. Formatea el código con la paleta de comandos → editor: format.

4Plan B: un servidor desde la terminal

Si no se puede instalar la extensión (p. ej. en un ordenador del aula), inicia un servidor desde la terminal. En los dos editores la terminal se abre con Ctrl + ` y ya está en la carpeta del proyecto.

Si tienes Node.js – con recarga automática:

npx live-server

La primera vez descarga el paquete y abre el navegador en http://127.0.0.1:8080.

Si tienes Python – sin recarga automática:

python3 -m http.server 8000

En Windows py -m http.server 8000. Después abre http://localhost:8000. Lo detienes con Ctrl + C.

5Cuando no funciona

¿Abriste toda la carpeta (Open Folder) y no solo un archivo? ¿Está la extensión Live Server instalada y activada? También ayuda reiniciar VS Code. El servidor también se puede iniciar con clic derecho en index.html → Open with Live Server.

Comprueba que guardaste el archivo: un archivo sin guardar tiene un punto ● en su pestaña. Mira la dirección en el navegador: si empieza por file://, la página no funciona a través del servidor. ¿Estás editando un archivo de la misma carpeta que sirve el servidor?

El cursor tiene que estar en un archivo .html que pertenezca a la carpeta abierta. Comprueba en la página de extensiones que LiveServer está instalado y reinicia Zed. Mientras lo solucionas, usa un servidor desde la terminal (parte 4).

En el mismo puerto ya funciona otro servidor (p. ej. de otra ventana del editor). Detenlo o deja que el servidor elija otro puerto: siempre verás el número en la dirección.

La ruta es relativa al archivo HTML y las mayúsculas y minúsculas importan: img/Logo.PNG no es lo mismo que img/logo.png. En un servidor web (también en GitHub Pages) ese error rompe la imagen aunque en Windows funcione por casualidad.

CSS – textos, fuentes y fondos

CSS (Cascading Style Sheets, hojas de estilo en cascada) decide cómo se ve una página: colores, letra, tamaños, espacios y fondos. HTML dice qué hay en la página; CSS, cómo se ve.

1Tres formas de añadir CSS

El atributo style directamente en la etiqueta. Solo afecta a ese elemento: en una página grande enseguida se vuelve un lío.

<h1 style="color: white; text-align: center;">Mi artículo</h1>

CSS en una etiqueta <style> dentro de la cabecera. Solo afecta a esta página: un sitio con muchas páginas tendría que repetir los estilos en cada una.

<head>
  <style>
    h1 { color: white; text-align: center; }
  </style>
</head>

Los estilos en un archivo aparte css/style.css, que enlazamos con la etiqueta <link> en la cabecera. El atributo rel="stylesheet" dice qué relación tiene el archivo con la página (es su hoja de estilos) y href, dónde encontrarlo. Todas las páginas del sitio pueden usar el mismo archivo. Esta es la forma que usaremos.

index.html
<head>
  <meta charset="UTF-8">
  <title>Mi artículo</title>
  <link rel="stylesheet" href="css/style.css">
</head>
css/style.css
h1 {
  color: white;
  text-align: center;
}

h1 { color: white; text-align: center; }

Empezamos: damos estilo a un artículo paso a paso

Haz clic en los pasos: el CSS se añade al editor y ves el resultado al instante. Después puedes cambiar el código tú mismo.

3Colores

El color del texto lo define la propiedad color, el del fondo background-color. Puedes escribir el valor con una palabra (hay más de 140) o con un código: todas las formas de la derecha significan el mismo color.

Código hex #rrggbb = rojo, verde y azul en hexadecimal (00 – ff). rgb() es lo mismo en decimal (0 – 255); hsl() = tono (0 – 360°), saturación y luminosidad en porcentaje.

4Dar estilo al texto

Juega con los controles: el CSS se escribe solo. font-family indica una lista de fuentes: el navegador usa la primera que encuentra en el ordenador y al final siempre va una familia genérica (sans-serif, serif, monospace) que seguro que encuentra. Conviene definir la familia de fuentes ya en body: toda la página la hereda.

6Fondos

      
Una imagen de fondo se indica con una ruta en url(). Cuidado: la ruta es relativa al archivo CSS, no al HTML. Desde css/style.css primero hay que salir de la carpeta css con ../ y solo después entrar en img: url("../img/hory.jpg").

      

        

        

          
Texto sobre el fondo

          

        

      

      

        
background-size
cover – la imagen cubre todo el elemento (algo puede quedar recortado). contain – la imagen entera cabe dentro (puede quedar espacio libre, que se rellena repitiéndola).

        
background-repeat
por defecto la imagen se repite; no-repeat desactiva la repetición, repeat-x / repeat-y solo en una dirección.

        
background-position
coordenadas x y desde la esquina superior izquierda: con palabras (right top), en porcentaje (10% 0%) o en px.

        
linear-gradient()
una transición de colores en lugar de una imagen. Encontrarás degradados ya hechos en uigradients.com.

      

      
background-attachment: scroll vs. fixed

      
Desplaza el texto en los dos recuadros. Con scroll (por defecto) el fondo se mueve con el contenido; con fixed se queda quieto.

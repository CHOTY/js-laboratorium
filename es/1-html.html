HTML – el esqueleto de cada página

HTML es un lenguaje de marcado: le dice al navegador qué hay en la página: un título, un párrafo, una imagen, un enlace, una tabla, un formulario. Cómo se ve lo resuelve CSS (lección 2) y qué pasa al hacer clic, JavaScript.

1Etiquetas, atributos y el esqueleto del documento

Una página se compone de etiquetas (tags). La mayoría van en pareja: una etiqueta de apertura y otra de cierre con el contenido en medio: <p>…</p>. Las etiquetas vacías no tienen contenido: <br>, <img>, <input>, <meta>. La información adicional se escribe en atributos dentro de la etiqueta de apertura: nombre="valor".

Haz clic en cualquier parte de la línea:

<a href="https://www.ukf.sk" target="_blank">Web de la UKF</a>
Elige una parte del código de arriba.

El esqueleto de cada página

<!DOCTYPE html>
<html lang="sk">
  <head>
    <!-- información sobre la página – no se ve -->
    <meta charset="UTF-8">
    <title>Título en la pestaña del navegador</title>
  </head>
  <body>
    <!-- todo lo que se ve en la página -->
    <h1>¡Hola, mundo!</h1>
  </body>
</html>

Archivos del proyecto

  • La página de inicio siempre se llama index.html: el navegador la abre cuando la dirección no indica un archivo concreto.
  • Nombra las demás páginas según su contenido (contacto.html): el nombre del archivo también formará parte de la dirección.
  • Guarda las imágenes en una carpeta img.
  • Las etiquetas se anidan como cajas: lo que se abre en último lugar se cierra primero – <p><strong>…</strong></p>.
  • El navegador ignora la sangría, pero a ti te ayuda a ver el anidamiento.

2La cabecera <head>: etiquetas meta, título, enlaces

El contenido de la cabecera no se ve en la página, pero lo leen el navegador y los buscadores. Aquí van las etiquetas meta (codificación, descripción, autor, viewport), el título de la pestaña del navegador y los enlaces a estilos, scripts y al icono favicon. 3Títulos, párrafos y formato del texto

      
Los títulos tienen 6 niveles; <h1> es el más importante. Cada página debería tener exactamente uno <h1>: con él los buscadores y los lectores de pantalla saben de qué trata la página. Cuidado con la escritura: el salto de línea es <br> (no </br>) y cada título se cierra con barra – <h6>…</h6>. La etiqueta <big> está obsoleta; el tamaño de letra se define en CSS (font-size).

    

  


  

    

      
4Enlaces e imágenes

      

        

          
Enlace <a>

          
    
            
  • href – adónde lleva el enlace (obligatorio). Una dirección completa https://www.ukf.sk, otro archivo del proyecto contacto.html o un lugar de la página #formulario.
    • 
            
  • target="_blank" – abre el enlace en una pestaña nueva.
    • 
            
  • href="tel:+421900123456" – en el móvil marca el número directamente.
    • 
            
  • href="mailto:info@firma.sk" – abre un correo nuevo.
    • 
          

        

        

          
Imagen <img> (etiqueta vacía)

          
    
            
  • src – ruta al archivo con su extensión (.jpg, .png, .gif, .svg). Obligatorio.
    • 
            
  • Ruta relativa img/slnecnica.jpg – un archivo de tu proyecto. Es la forma recomendada.
    • 
            
  • Dirección externa https://…/obrazok.jpg – carga un servidor ajeno y la imagen puede desaparecer en cualquier momento.
    • 
            
  • alt – una descripción en texto. La lee el lector de pantalla y se muestra cuando la imagen no se carga.
    • 
          

        

      

      

        

        

          
          

        

      

      


      

      
Una dirección externa siempre empieza por el protocolo: https://www.pagina.com/imagen.jpg (no http:www…). El atributo alt también puede llevar tildes: gracias a <meta charset="UTF-8"> el lector de pantalla las lee bien.

7Formularios

      
Un formulario <form> recoge datos y, al enviarlo, los manda a la dirección del atributo action. El atributo method define cómo: GET añade los datos a la dirección (p. ej. una búsqueda), POST los envía ocultos (registro, pedido). target="_blank" abriría la respuesta en una pestaña nueva.

      

        

          

            

            

            

            

              

            
Envío
              

              

            

            

            

            
          

        

        

          
Lo que se enviaría:

          
Rellena el formulario y haz clic en Enviar.

          
    
            
  • <label for="fEmail"> pertenece al campo con id="fEmail": haz clic en la etiqueta y el cursor salta al campo.
    • 
            
  • Se envían parejas name=valor. ¡Un campo sin atributo name no se envía!
    • 
            
  • type="email" comprueba el formato de la dirección, type="number" solo deja pasar números y required no permite dejar el campo vacío.
    • 
            
  • Los botones de opción (radio) con el mismo name forman un grupo: solo se puede elegir uno. Las casillas (checkbox) puedes marcar las que quieras.
    • 
            
  • <select> con el atributo multiple permite elegir varias opciones; size define cuántas filas se ven.
    • 
          

        

      


<form action="order.php" method="post">
  <label for="email">Correo electrónico</label>
  <input type="email" id="email" name="email" required>

  <input type="radio" id="post" name="delivery" value="post">
  <label for="post">Correo postal</label>
  <input type="radio" id="courier" name="delivery" value="courier">
  <label for="courier">Mensajería</label>

  <textarea id="note" name="note"></textarea>
  <input type="submit" value="Enviar">
</form>


    

  


  

    

      
8Comentarios, herramientas de desarrollo y etiquetas semánticas

      

        

          
Comentario

          
Una nota para el programador: el navegador no la muestra, ni siquiera dentro de <body>.


<!-- Esto es un comentario. Empieza con <!-- y termina con -->

          
Al principio hay dos guiones normales <!--, no una raya larga.

        

        

          
Herramientas de desarrollo (DevTools)

          
En cualquier página haz clic derecho → Inspeccionar o pulsa F12. En la pestaña Elements ves el HTML de toda la página, puedes editarlo temporalmente y debajo ves también el CSS. Con los tres puntos ⋮ eliges en qué lado de la ventana aparece el panel. ¡Pruébalo en esta página!

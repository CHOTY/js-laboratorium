# Úlohy k hodine JS 3 – funkcie a udalosti

Výklad a hotové ukážky: <https://choty.github.io/js-laboratorium/js3.html>

Každý priečinok otvor vo VS Code a spusti cez Live Server.

| Priečinok | Úloha | Čo je pripravené | Čo urobíš ty |
|---|---|---|---|
| `1-funkcie` | Zadanie 1 – tri typy funkcií | HTML s odsekmi, `js/app.js` so zadaním | napíšeš funkcie `ahoj`, `pozdravMeno`, `obsahStvorca` |
| `2-navigacia` | Úloha 2 – navigácia | HTML, CSS a pôvodný JS s `onclick` | prerobíš ho na `addEventListener` |
| `3-akordeon` | Úloha 3 – akordeón | HTML a CSS | vytvoríš a pripojíš `js/accordion.js` |
| `4-kalkulacka` | Úloha 4 – kalkulačka bez `onclick` | HTML a CSS (bez JS, bez `onclick`) | vytvoríš a pripojíš `js/kalkulacka.js` |
| `5-hodnotenie` | Úloha 5 – hodnotenie hviezdičkami | HTML a CSS | vytvoríš a pripojíš `js/hodnotenie.js` |

Celé zadania aj nápovedy sú v sekcii [Úlohy na hodinu](https://choty.github.io/js-laboratorium/js3.html#ulohy).

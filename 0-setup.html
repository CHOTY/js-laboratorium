Editor a lokálny server

Skôr než napíšeme prvý riadok HTML, pripravíme si editor tak, aby sa stránka v prehliadači po každom uložení sama obnovila. Vyber si VS Code alebo Zed – obidva sú zadarmo a fungujú na Windows, macOS aj Linuxe.

1Prečo nestačí dvojklik na súbor?

Keď HTML súbor otvoríš dvojklikom, prehliadač ho načíta priamo z disku (adresa začína file://). Na prvé pokusy to stačí, no zmeny musíš zakaždým obnoviť ručne a niektoré veci, ktoré budeme robiť neskôr, takto nefungujú vôbec. Lokálny server je malý program, ktorý tvoj priečinok „podáva“ prehliadaču ako skutočná webová stránka – na adrese http://127.0.0.1:… (127.0.0.1 alebo localhost = tvoj vlastný počítač).

  • Po uložení súboru sa stránka obnoví sama
  • Načítanie iného súboru cez JavaScript (fetch()) – budeme potrebovať v lekcii XML
  • JavaScriptové moduly (<script type="module">)
  • Cesty od koreňa webu, napr. /img/logo.png
  • Bežné HTML, CSS a obrázky s relatívnou cestou (img/logo.png)

2Jeden projekt = jeden priečinok

Editor aj server pracujú s celým priečinkom, nie s jedným súborom. Vytvor si preto na disku priečinok (napr. na Ploche) a v ňom súbor index.html – prehliadač ho otvorí ako úvodnú stránku. Ďalšie súbory si dáme do podpriečinkov.

my-website/ ├── index.html ← úvodná stránka ├── css/ │ └── style.css ← lekcia 2 ├── img/ │ └── logo.png └── js/ └── app.js ← JS 1

Do index.html vlož túto kostru (vo VS Code ju napíše skratka ! a Tab):

<!DOCTYPE html>
<html lang="sk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Moja prvá stránka</title>
</head>
<body>
  <h1>Ahoj, svet!</h1>
  <p>Ak to vidíš na adrese http://127.0.0.1, server funguje.</p>
</body>
</html>

Tip: v názvoch súborov a priečinkov nepoužívaj medzery ani diakritiku – moja-stranka.html, nie Moja stránka.html.

3Nastavenie editora krok za krokom

Vyber si jeden editor. Na cvičeniach budeme ukazovať VS Code, ale všetko funguje rovnako aj v Zede.

  1. Stiahni a nainštaluj VS Code

    Stiahni ho z code.visualstudio.com/Download pre svoj systém a nainštaluj. Na Windows nechaj zaškrtnuté Add to PATH a Open with Code – priečinok potom otvoríš pravým klikom.

  2. Otvor priečinok projektu

    Menu File → Open Folder… a vyber priečinok my-website (nie samotný súbor). Ak sa VS Code opýta, či dôveruješ autorom súborov, klikni Yes, I trust the authors.

  3. Nainštaluj rozšírenia

    Vľavo klikni na ikonu Extensions (štyri štvorčeky) alebo stlač Ctrl + Shift + X. Vyhľadaj a pri každom klikni Install:

    Live Server
    autor Ritwick Dey
    lokálny server s automatickým obnovením
    Auto Close Tag
    autor Jun Han
    sám dopíše uzatváraciu značku
    Prettier – Code formatter
    autor Prettier
    upraví odsadenie kódu

  4. Vytvor index.html

    V paneli Explorer klikni na ikonu New File, napíš index.html. V prázdnom súbore napíš !, stlač Tab (Emmet vloží kostru stránky) a ulož Ctrl + S.

  5. Spusti server – Go Live

    Vpravo dole v modrom stavovom riadku klikni na Go Live. Ďalšie možnosti: pravý klik na index.html → Open with Live Server, alebo Alt + L, potom Alt + O. Otvorí sa prehliadač s adresou http://127.0.0.1:5500/index.html.

    index.html — my-website
    Ln 9, Col 5UTF-8HTML⦿ Go Live

  6. Uprav, ulož, pozri

    Zmeň text v <h1> a ulož. Prehliadač sa obnoví sám. Aby si nemusel stále ukladať, zapni File → Auto Save. Neporiadny kód upraví Prettier: pravý klik → Format Document (Shift + Alt + F).

  7. Zastav server

    V stavovom riadku je teraz namiesto Go Live nápis Port : 5500 – kliknutím server zastavíš (alebo Alt + L, Alt + C).

  1. Stiahni a nainštaluj Zed

    Stiahni ho z zed.dev/download (macOS, Linux aj Windows). Na Linuxe ho nainštaluješ aj príkazom curl -f https://zed.dev/install.sh | sh.

  2. Otvor priečinok projektu

    Menu File → Open… (Ctrl + O) a vyber celý priečinok my-website. Súbory uvidíš vľavo v paneli Project.

  3. Nainštaluj rozšírenie LiveServer

    Otvor stránku rozšírení: Ctrl + Shift + X, alebo príkazová paleta Ctrl + Shift + P → zed: extensions. Vyhľadaj LiveServer (autor frederik) a klikni Install. Podporu HTML si Zed doinštaluje sám pri prvom otvorení .html súboru. Ak chceš skratky ako vo VS Code, pridaj aj rozšírenie Emmet.

  4. Vytvor index.html

    Pravý klik na priečinok v paneli Project → New File, napíš index.html a vlož kostru stránky z časti 2 (s rozšírením Emmet napíš ! a vyber návrh z ponuky). Ulož Ctrl + S.

  5. Otvor stránku v prehliadači – Code Action

    Klikni do textu súboru index.html pravým tlačidlom a vyber Code Actions, alebo stlač Ctrl + . (bodka). V ponuke vyber akciu rozšírenia LiveServer – stránka sa otvorí v prehliadači a Zed ti ukáže, na akom porte server beží. Server beží stále, kým máš projekt otvorený, nič ďalšie nespúšťaš.

    <h1>Ahoj, svet!</h1>
    ⚡ LiveServer: open in browser
    …

    Presný názov akcie sa môže podľa verzie rozšírenia trochu líšiť.

  6. Uprav a sleduj prehliadač

    Zmeny sa prejavia hneď – podľa nastavenia už počas písania alebo po uložení. Pri zmene CSS sa vymení len štýl, pri inej zmene sa stránka obnoví. Kód naformátuješ cez príkazovú paletu → editor: format.

4Záloha: server z terminálu

Ak rozšírenie nejde nainštalovať (napr. na školskom počítači), spusti server z terminálu. Terminál otvoríš v oboch editoroch skratkou Ctrl + ` a je už v priečinku projektu.

Ak máš Node.js – s automatickým obnovením:

npx live-server

Prvé spustenie si balík stiahne, otvorí prehliadač na http://127.0.0.1:8080.

Ak máš Python – bez automatického obnovenia:

python3 -m http.server 8000

Na Windows py -m http.server 8000. Potom otvor http://localhost:8000. Zastavíš ho Ctrl + C.

5Keď to nejde

Otvoril si celý priečinok (Open Folder), nie iba súbor? Je rozšírenie Live Server nainštalované a zapnuté? Pomôže aj reštart VS Code. Server vieš spustiť aj pravým klikom na index.html → Open with Live Server.

Skontroluj, či si súbor uložil – neuložený súbor má na karte bodku ●. Pozri adresu v prehliadači: ak začína file://, stránka nebeží cez server. Upravuješ súbor z toho istého priečinka, ktorý server podáva?

Kurzor musí byť v .html súbore, ktorý patrí do otvoreného priečinka. Over na stránke rozšírení, či je LiveServer nainštalovaný, a reštartuj Zed. Kým to vyriešiš, použi server z terminálu (časť 4).

Na tom istom porte už beží iný server (napr. z iného okna editora). Zastav ho, alebo nechaj server zvoliť iný port – číslo vždy uvidíš v adrese.

Cesta je relatívna k HTML súboru a záleží na veľkých a malých písmenách: img/Logo.PNG nie je to isté ako img/logo.png. Na webovom serveri (aj na GitHub Pages) by takáto chyba nefungovala ani vtedy, keď to na Windows náhodou funguje.
